## Outcome

`gm assets facets --collections` lists all 414 packs with a schema-valid collection card whose `license` is an SPDX id or a `LicenseRef-*` id from one table, every `LicenseRef-*` and quarantined card carries `processing: local-only`, the 8 uncarded packs (LimeZu ×5, ansimuz, hattap, quaternius) and the 128 Sidetrax drafts are resolved, and `install_itch_pack.py` writes a rights shape the schema accepts.

## Context and evidence

The catalog carries five licence values that are neither SPDX nor `LicenseRef-` (`sidetrax-royalty-free` 128, `synty-personal` 13, `LimeZu-commercial` 5, `ansimuz-free-commercial`, `custom-commercial-ok`), and `install_itch_pack.py:362-368` writes `redistribution: 'not-allowed'` with `basis` as a string, both rejected by the schema (E05-2). `build_collection_cards.py` knows only Kenney and Synty ceilings, so the 8 non-Kenney/Synty/Sidetrax packs have no card and are invisible to `gm assets search` (E05-2, E05-3). The rule "no cloud processing of paid assets" is not encoded in rights; OGM-004 adds `processing: local-only | any` to the schema and this ticket applies the default (E05-10). Kevin confirmed Kenney and Synty licences on 2026-10-26 (`build_collection_cards.py` LICENSES) and the Sidetrax interpretation on 2026-10-27 (C3 §18 Q10); family-only use of every owned pack is recorded in memory (`sidetrax-private-artifacts-ok`).

Resolved already: `pack.json` keeps its old `license` strings (originals are never rewritten; the table is the read alias C3 §9 asks for); cards use SPDX/`LicenseRef-*`; `vision-input` keeps its name (D-CARDS); no describe tags are invented for packs that have none (they stay `draft`, not `tagged`).

## Scope

- `packages/asset-cards/src/licenses.ts`: the licence table, one row per catalog value and per vendor class → `{id, spdxOrRef, ceiling: {uses, audience, redistribution, attribution, forbids?}, processing, ref, note, confirmed_by?, confirmed_on?}`; `pnpm --filter @ogm/asset-cards licenses:emit` writes `packages/asset-cards/data/licenses.json` (checked in) for the Python callers; a test asserts the emitted file matches the table.
- `scripts/assets/build_collection_cards.py`: reads `data/licenses.json` instead of its `LICENSES` dict, handles every vendor in the table, writes `rights.processing`, keeps `data/collection_tags.jsonl` describe tags where present and otherwise writes `status: draft` with `describe` seeded from the title (`by: filename`); idempotent (re-runs change nothing but `provenance.*.at` when content is equal, so it preserves `at` on unchanged cards); never overwrites a card whose provenance has `locked: true` fields.
- Sidetrax: the 128 collection cards get the confirmed licence basis (`LicenseRef-sidetrax-royalty-free`, in-game, private, in-build) plus the existing `interpretation` entry (vision-input, local models only) and `processing: local-only`; status follows the C3 rule (`tagged` only when `describe.description`, `objects` and `roles` exist, else `draft`).
- `scripts/assets/install_itch_pack.py`: `usage_rights` → the schema's shape (`redistribution: 'none'`, `basis: [{type: 'license', …}]`), `LicenseRef-itch-custom` default id, and a `--license-id` flag.
- A one-shot run on this machine over all 414 packs, then `python3 -I scripts/assets/build_catalog.py`; the report (per vendor: cards written, status counts, validation failures) pasted into the PR.

## Contract and invariants

Licence table (producer; consumers OGM-062 `why`, OGM-064 import, OGM-068 mirrors, OGM-039 gate through the lockfile):

```ts
// packages/asset-cards/src/licenses.ts
export type LicenseRow = {
  id: string;                                  // 'CC0-1.0' | 'LicenseRef-synty-personal' | …
  aliases: string[];                           // catalog/pack.json values: 'synty-personal', 'sidetrax-royalty-free', …
  ceiling: { uses: Use[]; audience: 'private' | 'public'; redistribution: 'none' | 'in-build' | 'free'; attribution: string | null; forbids?: Use[] };
  processing: 'local-only' | 'any';            // local-only for every LicenseRef-* row
  ref: string; note: string;                   // where the terms were read; never a link with a key or serial
  confirmed?: { by: 'kevin'; on: string };     // omitted = unconfirmed: the default basis applies (C3 §5)
};
export const LICENSES: LicenseRow[];
export function licenseFor(value: string): LicenseRow | undefined;  // by id or alias
```

Rows: `CC0-1.0` (any, confirmed 2026-10-26), `LicenseRef-synty-personal` (all uses, private, in-build, local-only, confirmed 2026-10-26), `LicenseRef-sidetrax-royalty-free` (in-game + vision-input, private, in-build, local-only, confirmed 2026-10-27, `forbids: [edit-audio, derive-audio]` not granted), `LicenseRef-limezu-commercial` (in-game, placeholder, style-reference, vision-input; private; in-build; local-only; confirmed per memory, date = run date), `LicenseRef-ansimuz-free` (in-game, placeholder, style-reference, vision-input; public; in-build; attribution "ansimuz"; local-only), `LicenseRef-itch-custom` (in-game, placeholder, vision-input; private; in-build; local-only; unconfirmed until read), `NOASSERTION` (default basis only).

Invariants: every card's stored `rights` equals `effectiveRights(basis)` (OGM-004 check); `processing` is `local-only` whenever `license` starts with `LicenseRef-` or `status` is `quarantined`; the migration is idempotent; `pack.json` is never written by this ticket.

## Failure, security, migration and accessibility cases

The migration writes only `assets-local/packs/*/collection.card.json` (gitignored) and `data/licenses.json`; it never prints or stores download links, order numbers or serials (the `ref` field is a path or a vendor page name). A schema failure on any card aborts the write of that card and is listed in the report. No DB migration; no UI.
