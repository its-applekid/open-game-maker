## Outcome

`services/rooms` starts as `ogm-rooms.service` on `127.0.0.1:$OGM_ROOMS_PORT`, answers `GET /healthz`, creates rooms through a loopback internal API, and runs a relay-only `GameRoom` that verifies grants offline, enforces owner-only messages, stamps `playerIndex`, caps sizes and rates, zeroes private presence, broadcasts phase, handles reconnection windows, a second owner device, host-leave end-and-record, draft load/ready, idle dispose and revocation, with a `@colyseus/testing` test for every rule.

## Scope

- `services/rooms` (`@ogm/rooms`): Node 24 entry binding `127.0.0.1`, Colyseus `Server` with `WebSocketTransport` on the same `http` server as a Hono app serving `GET /healthz` and the loopback internal API (`POST /internal/rooms`, `POST /internal/rooms/:roomId/revoke`, bearer `OGM_ROOMS_INTERNAL_SECRET`).
- `GameRoom`: `onAuth` → `verifyGrant` + revocation set + `protocol`/`buildId` checks mapped to `JoinRejection`; `ownerId` and pin from the create call, never from a client; `playerIndex` = lowest free index, stable across reconnection, owner reserved 0; `welcome` on join; per-type rate and size caps from `LIMITS` (drop and count); `input` relayed to the editor session with `playerIndex` and `from` stamped; `snapshot`/`event` accepted only from the editor session and broadcast to all but it; `design.tx` validated (`validateDesignTx` against the pin), `lastRev` updated, relayed to all but sender; `presence` zeroed while `privateMode`; `phase` with `phaseAt` server time and `playRev = lastRev`; `draft.load` (url must start with `OGM_GAMES_ORIGIN`) → `migrating`, `draft.ready` from every connected member → pin updated, `editing`; `kick`; `ping`/`pong`.
- Lifecycle: `allowReconnection(client, owner ? 120 : 60)`; owner editor drop → `pausedForHost`, restore on return; timeout with no owner session → `ended: host-left`, `POST $OGM_API_INTERNAL_URL/internal/rooms/:roomId/ended {reason, endedAt}`; owner consented leave → `owner-closed`; player timeout frees the index; second owner device → `sessions[]` grows, `editorSessionId` = newest, old socket demoted; idle (no clients) 300 s → `ended: idle`, dispose; revoke by `jti` or `userId` → `ended: revoked` to that client, then leave.
- `ops/systemd/ogm-rooms.service` is OGM-002's file; this ticket ships `services/rooms/README.md` with the `ExecStart` line and env names (`OGM_ROOMS_PORT`, `OGM_WS_TOKEN_SECRET`, `OGM_ROOMS_INTERNAL_SECRET`, `OGM_API_INTERNAL_URL`, `OGM_GAMES_ORIGIN`).

## Contract and invariants

Consumer of the room protocol: copy from OGM-050 `packages/contracts/src/room.ts` and `@ogm/room-protocol`; do not redefine. Server rules, verbatim from T07 §4.1: "`onAuth` verifies the grant, `ownerId` comes from the backend's room record at creation, never from a client; every owner-only message from a non-owner is dropped and counted; rate and size caps per type as annotated; `presence` fields are zeroed while `privateMode`; `allowReconnection(client, role === 'owner' ? 120 : 60)`; owner drop → `pausedForHost`; timeout → `ended: host-left` and `POST /internal/rooms/:id/ended`; room idle (no members) 5 min → dispose."

Internal API this ticket defines (loopback only, consumed by OGM-052):
```
POST /internal/rooms            Authorization: Bearer $OGM_ROOMS_INTERNAL_SECRET
  { gameId, branchId, buildId, ownerId, maxPlayers }  → 201 { roomId }
POST /internal/rooms/:roomId/revoke   { jti?: string; userId?: string }  → 204 | 404
POST /internal/rooms/:roomId/ended    (rooms → API, same secret) { reason: 'host-left'|'owner-closed'|'idle'|'revoked', endedAt: string }
GET  /healthz → { ok: true, service: 'rooms', version, uptimeSec, rooms: n }
```
Invariants: the room holds no design state beyond `lastRev`; it never reads a lease token; snapshot and event bytes are opaque; a message from a session that is not `editorSessionId` for owner-only types is dropped and counted, never answered; `maxPlayers` clamps to `LIMITS.maxPlayersCeiling`; watchers count as members (they become players at Play).

## Failure, security, migration and accessibility cases

Grant secret and internal secret are read by name through `@ogm/config` from the unit's env file (0600) and never logged; the internal API is loopback only and bearer-checked in constant time; a wrong bearer is 401 with no body. A malicious player sending owner-only or oversized messages is dropped and counted, never disconnected by default (counts visible in `/healthz`); 1,000 violations per minute from one session → `leave(4002)`. Loss of the API during the ended callback: retry 3× with backoff, then log; the room still disposes. No DB, no migration, no UI. Clock: `phaseAt` is `Date.now()` on the server; clients never trust their own clock for phase.
