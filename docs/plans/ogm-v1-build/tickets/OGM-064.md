## Outcome

A drop that `drive_sync.py` has settled into `assets-local/inbox/quarantine/<dir>/` becomes, with no hand-written JSON, a quarantined collection card under `assets-local/packs/<id>/` (or `inspiration/<id>/`), safely unpacked, measured (glTF geometry and rig, images, fonts), with image thumbnails, and an `intake.json` next to its manifest; `services/intake` does this for every open queue entry on its own, and `gm-asset-intake` is left with the licence judgment and the admin's confirmation.

## Scope

- `gm packs import <dir|archive> --id <vendor-name> [--license <SPDX|LicenseRef-x>] [--inspiration] [--version <v>] [--from-queue <drop_id>] [--json]`: C3 §13 steps 1 (quarantine card: `status: quarantined`, `license: NOASSERTION`, default basis, `processing: local-only`), 4 (identify: one card per logical asset; drop `.meta`, `.uasset`, Unity/Unreal projects; never keep executables; `kind/subkind` from extension and folders; Synty `MaterialList_*.txt` and Kenney `Tilesheet.txt` parsed; `describe` seeded from filenames `by: filename`; `collection_info.hash_manifest` over every file), 5 (measure, below), 6 (image thumbnails as WebP under `assets-local/previews/<hash prefix>/`), 8 (validate with `@ogm/contracts`; failures keep `needs-review`) and 10 (`counts`, suggested `family_coverage`, never `creation_choice`); writes `pack.json` in the `local-asset-library.md` shape so `build_catalog.py` keeps working; originals go to `<id>/<version>/originals/`, unpacked content to `extracted/`.
- Licence confirmation sub-mode: `gm packs import --confirm <collection-id> --license <id> --confirmed-by kevin [--note "…"] [--decision uses=a,b audience=private redistribution=none note="…"]` rewrites the collection card's basis from the OGM-061 licence table (or an explicit SPDX), recomputes effective rights, moves `quarantined` → `draft` (or `measured` when measured), and closes `intake.json` as `imported`.
- Safe unpack in TypeScript: zip via `adm-zip` with a per-entry path check (never `extractAllTo`), tar/tgz/`.unitypackage` via `tar` (≥ 1k stars) with a `filter` that rejects absolute paths, `..`, links and devices, 7z/rar via the `7z` binary after listing with `7z l -slt` and refusing unsafe members; nested archives one extra pass; size and member caps from the manifest; never executes anything.
- `packages/asset-measure` (`@ogm/asset-measure`): `measureGltf` (bounds_m, pivot, triangles, vertices, materials, texture_keys; `rig_type`, `rig_id` = sha256 of joint names plus joint-only parent links (C3 §3), `joint_count`, `clips[]` with canonical names from a synonym table), `measureImage` (sharp: size, alpha, indexed colours, `pixel_art` heuristic), `measureFont` (`opentype.js`: family, style, weight, glyph_count, monospace), `measureAudio` left to the Python workers (OGM-065). FBX/OBJ/blend → `flags: ['needs-conversion']`.
- `services/intake` (`@ogm/intake`): polls `assets-local/inbox/queue.jsonl` every 30 s, treats an entry as open when no `intake.json` exists, skips `integrity_ok: false` with `{status: blocked, reason}`, detects duplicates by `drop_id` + MD5 set, runs `gm packs import --from-queue` (known vendor markers → `--license`; else the drop stays quarantined with `intake.json {status: awaiting-license}`), writes `~/.local/state/ogm/intake/status.json` (counts and last 50 jobs) for the admin API, emits `intake.*` events, runs its children with `nice -n 10`; binds no port; entrypoint `services/intake/src/main.ts` for the unit OGM-002 ships.
- `.claude/skills/gm-asset-intake/SKILL.md` rewritten to: read status, inspect `license_files`, judge the licence, ask Kevin, run `gm packs import --confirm …`, report one line per drop.

## Contract and invariants

Intake job (owner T05; producer `drive_sync.py`; consumers this service and the admin UI), quoted from T05 §4:

> One line of `assets-local/inbox/queue.jsonl`: `{"drop_id", "name", "manifest": "<path>", "time"}`; `manifest.json` carries `files[]`, `license_files[]`, `problems[]`, `integrity_ok`, `usage_rights` (strict default); `intake.json` `{status: imported|awaiting-license|blocked|duplicate, collection, license, rights, confirmed_by, date}` ends the job.

(`drive_sync.py:758` writes `queued_at`, `drop_id`, `name`, `revision`, `manifest`; the service reads those keys and treats `time` as `queued_at`.)

```ts
// packages/asset-measure/src/index.ts
export function measureGltf(file: string): Promise<{ geometry: Geometry; rig?: Rig; anim?: Anim; flags: string[] }>;  // Geometry/Rig/Anim from @ogm/contracts card schema
export function measureImage(file: string): Promise<{ image: Image; look?: Look }>;
export function measureFont(file: string): Promise<{ font: Font }>;
export function rigId(joints: { name: string; parentJoint: string | null }[]): string;  // "rig:" + sha256 prefix 12
```

Invariants: a drop is never unpacked when `integrity_ok` is false; nothing from a drop is executed; the status of a collection leaves `quarantined` only through `--confirm` (a human-named `confirmed_by`); `processing` is `local-only` until a confirmed licence says `any`; `intake.json` is written exactly once per queue entry; Drive files and quarantine folders are never deleted by code.

## Failure, security, migration and accessibility cases

Untrusted bytes: unpack into a fresh empty directory, path-check every member, caps from the manifest, no execution, read-only after copy; the service holds no credentials (the listener's service-account key is read by the listener alone from `~/.config/ogm`, never by this service); `intake.json` never contains links, keys or serials; a crash mid-import leaves no `intake.json`, so the job is retried and the partially written `<id>/<version>/` directory is cleared before retry; the service refuses to run if `assets-local/inbox` is not under the library root. No DB migration; no UI.
