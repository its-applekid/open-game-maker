## Outcome

`@gm/sdk/fx` renders any vendored pixelfx effect into a Phaser texture (2D) and ports `fx.js`'s instanced-quad particle system as data-driven 3D sprites planned from scene time; `@gm/sdk/nav` finds grid paths with a built-in A* and loads recast only when a game declares the `nav.navmesh` capability; `@gm/sdk/proc` exposes seeded FastNoise Lite with `fbm` and `ridge` helpers; every function is deterministic for a given seed and the unit suite runs in Node.

## Context and evidence

Effects are agent-authored data in this product (B5); Effekseer needs a Windows editor and is out (E04-10). The repo already has `third_party/pixelfx` (MIT, pinned `fe7103c`, 234 effects, plain ESM, no dependencies; E12-10) for 2D, and `prototypes/title-city/fx.js` proved a 3D particle system that is a pure function of time, one `InstancedMesh` per texture (E04-10, E04-3). Grid pathfinding needs no WASM; recast-navigation-js (0.43.1, MIT) is the only 3D navmesh option and sits below the 1k-star rule, so it is optional and lazily loaded behind a capability (E04-9). The title town carries inline value noise, `fbm` and `ridge` (`city.js:27-36`); FastNoise Lite's dependency-free JS port replaces it, seeded from the SDK RNG (E04-11). Resolved, do not reopen: pixelfx is consumed in place through a path alias and bundled into `@gm/sdk/fx`, never copied or edited (E12-10, `gm-asset-variants` rule); recast is an optional peer dependency and the exception request is recorded for Kevin in the PR, not decided here; Jolt and Effekseer stay out.

## Scope

- `packages/sdk/src/fx/`: `pixel.ts` (`renderEffect(effectModule, { palette, seed, frames }) → { frames: ImageData[]; fps; loop }` using pixelfx `createFx`/`createFrame`/`clearFrame`/`composite`; `toPhaserTexture(scene, key, rendered)` → `scene.textures.addSpriteSheet` from one canvas; `listEffects()` from the vendored `src/fx/**` index), `sprites3d.ts` (port of `fx.js`: `class Fx3d { add(kind, p); reserve(n); burst(t, pos, s); dust/flash/debris/splash/ring/decal/fire; build(); update(t); reseed(s) }` with textures resolved by asset id through OGM-026's `AssetLoader.texture` instead of `models/fx/*.png`, uniforms (`night`, fog) passed in, no `Math.random`), `fx/index.ts`.
- `packages/sdk/src/nav/`: `grid.ts` (`findPath(grid: Uint8Array | number[][], w, h, from, to, { diagonal = false, cutCorners = false }) → [x, y][] | null`, binary heap, Manhattan/octile heuristic, ≤ 80 lines), `navmesh.ts` (`loadNavmesh(capabilities)`: throws `NavUnavailable` unless `capabilities.has('nav.navmesh')`, then `await import('recast-navigation')` with a typed facade `{ build(positions, indices, cfg); findPath(a, b) }`), `nav/index.ts`.
- `packages/sdk/src/proc/`: `noise.ts` (`createNoise(seed, { type = 'OpenSimplex2', frequency = 0.01 }) → { at2(x, y); at3(x, y, z) }` over `fastnoise-lite`; `fbm(noise, x, y, { octaves = 5, lacunarity = 2.03, gain = 0.5 })`; `ridge(noise, x, y, { octaves = 6, lacunarity = 2.1, gain = 0.5 })` matching `city.js:34-35` constants), `proc/index.ts`.
- One `export * as fx`, `nav`, `proc` line each in `packages/sdk/src/index.ts`; tsconfig/vite alias `pixelfx/*` → `third_party/pixelfx/src/*`; `packages/sdk/THIRD_PARTY.md` carrying pixelfx's `NOTICE.md` text.

## Contract and invariants

Consumer: `Runtime`, `Rng` from OGM-022; `AssetLoader` from OGM-026 (texture by id); `Tier` and capabilities from OGM-020's `hello`. This ticket's public shape:

```ts
// @gm/sdk/fx
export function renderEffect(effect: PixelFxModule, opts: { palette?: string | string[]; seed: number; frames?: number }): { frames: ImageData[]; fps: number; loop: boolean; w: number; h: number };
export function toPhaserTexture(scene: Phaser.Scene, key: string, r: ReturnType<typeof renderEffect>): string;
export class Fx3d { constructor(scene: THREE.Scene, camera: THREE.Camera, textures: Record<FxKind, THREE.Texture[]>, uniforms: FxUniforms, rng: Rng); add(kind: FxKind, p: Particle): Particle; reserve(n?: number): void; burst(t: number, pos: Vec3, s?: number): void; dust(t, pos, s?, color?): void; flash(t, pos, s?): void; debris(t, pos, dir, s?): void; splash(t, xz, s?): void; ring(t, pos, s?): void; decal(t, end, kind, pos, s): void; fire(t, end, pos, s?): void; build(): void; update(t: number): void; reseed(seed: number): void }
// @gm/sdk/nav
export function findPath(grid: ArrayLike<number>, w: number, h: number, from: [number, number], to: [number, number], opts?: { diagonal?: boolean; cutCorners?: boolean }): [number, number][] | null;
export function loadNavmesh(capabilities: ReadonlySet<string>): Promise<Navmesh>;   // rejects NavUnavailable without 'nav.navmesh'
// @gm/sdk/proc
export function createNoise(seed: number, opts?: { type?: 'OpenSimplex2' | 'Perlin' | 'Value' | 'Cellular'; frequency?: number }): { at2(x: number, y: number): number; at3(x: number, y: number, z: number): number };
export function fbm(n: Noise2, x: number, y: number, o?: { octaves?: number; lacunarity?: number; gain?: number }): number;
export function ridge(n: Noise2, x: number, y: number, o?: { octaves?: number; lacunarity?: number; gain?: number }): number;
```

Invariants: `renderEffect` with the same effect, palette and seed yields byte-equal frames (pixelfx effects are seeded; the adapter passes `seed` through `resolveOptions`); `Fx3d.update(t)` is a pure function of `t` and the planned particles (no state from previous calls except the pool cursor), so `update(5)` after `update(9)` draws the same frame as a fresh `update(5)`; `findPath` returns the shortest path for 4-connected grids (BFS-equal length) and `null` when unreachable; `loadNavmesh` never imports recast when the capability is absent (the dynamic import is the only reference, so bundlers tree-shake it); `createNoise(seed).at2` is identical across runs and platforms (pure JS port); no `Math.random`/`Date.now` under `src/{fx,nav,proc}` (grep test; `Fx3d` takes the SDK `Rng`).

## Failure, security, migration and accessibility cases

A pixelfx effect module that throws during render rejects `renderEffect` with the effect name; it never crashes the game loop. `loadNavmesh` failure to import (package absent) rejects `NavUnavailable` with a message naming the optional dependency and the exception rule; games must boot without it (A4 §5 "missing capabilities leave a playable game"). No network, no secrets; pixelfx is MIT with the Patch Pixel font excluded (`NOTICE.md`, the vendored tree has no `gallery/`). No migrations, no UI.
