## Outcome

`@gm/host` mounts a game build from the games origin in a sandboxed iframe, completes the `hello` → `ready` handshake over a validated MessageChannel, is the only code that reads gamepads (stamping `playerIndex`), draws the touch stick and buttons from the game's declared actions in a layer that passes other touches to the game, sends viewport, safe area and settings, forwards `audio.relay` and `save.write` to app callbacks, and ships the games-origin service worker that keeps content-hashed assets across builds; an app that calls `createGameFrame()` with a role callback cannot be made to apply a design edit the role forbids.

## Context and evidence

- E04-1, E04-5: the contract is message-based; the prototypes' `postMessage('*')` is evidence of the message set, not code; the host validates every inbound message with Zod, caps 256 KB, limits 120 msg/s, drops unknown `t`, checks the role before forwarding `design.apply` (A4 §4 rules 2–3). OGM-021 owns the transport; this ticket owns what rides on it.
- E04-13, E09-14, B7 §5.3: one gamepad reader, in the host; the game never calls `getGamepads()`; the overlay is host-rendered from declared actions, ≥44 pt (64 px primary here, R113), hidden when a keyboard or pad is in use; a host overlay over a cross-origin iframe steals pointer events, so the layer is `pointer-events: none` with controls `auto`.
- E07-12: `playerIndex` is assigned by the room server for network players; locally the host assigns pad devices to local player indices and never trusts a frame's index from the game.
- D-GAMES-ORIGIN supersedes T04 §4's per-game subdomain: the `src` is `<gamesOrigin>/g/<gameId>/<buildId>/index.html?build=<kind>&protocol=1`. T09 E09-4's `microphone` in `allow` is dropped (A4 §4 rule 1: the game never holds the microphone; D-VOICE-ZERO keeps voice in the app).

## Scope

- `createGameFrame(opts)` → `GameFrame`: iframe with `sandbox="allow-scripts allow-same-origin allow-pointer-lock"`, `allow="autoplay; fullscreen; gamepad"`, `src` from `{gamesOrigin, gameId, buildId, build}`; refuses a `gamesOrigin` equal to the app origin.
- `HostBridge`: wraps OGM-021's host side; `hello` payload from opts; inbound parsed with OGM-020's `GameToHostSchema`; outbound `design.apply` and `mode.set` pass `opts.role()` through `canApply(role)` first; `request('test.*')` returns the correlated `test.result`; typed `on(t, cb)`.
- `GamepadPoller`: one rAF loop over `navigator.getGamepads()`; device → local `playerIndex` claim on first button press; maps buttons and axes to the manifest's declared actions; emits `input.frame` (`source: 'gamepad'`) when a value changed and every 250 ms as keepalive; exposes raw `PadSnapshot` for the app's menu navigation (OGM-071).
- `TouchOverlay`: from `manifest.inputs` (declared actions, `touch: 'stick' | 'two-stick' | 'tap'`), one or two sticks plus buttons in thumb zones, 64 px primary and 44 px secondary targets, pointer capture, `touchstart` preventDefault on controls and `gesturestart` cancel (dungeon.js), hidden 2 s after any key or pad input; emits `input.frame` (`source: 'touch'`).
- `ViewportTracker`: sizes the iframe to its container, reads `env(safe-area-inset-*)` through a probe and `visualViewport`, sends `viewport {w, h, dpr, orientation, safe}` on change.
- `setSettings({mute, volume, textScale, reduceMotion})` → `settings` message, resent after every `ready`.
- Callbacks: `onReady(manifest, marks)`, `onSaveWrite(payload)`, `onEvent(kind, payload)`, `onAudioRelay(msg)`, `onRawKey`, `onError`.
- `sw/game-cache.ts`: a service worker for the games origin, built to `dist/game-cache.js`: network-first for `index.html`, cache-first for `/g/*/assets/*` keyed by URL (content-hashed) in one `gm-assets` cache shared across builds, stale-while-revalidate otherwise; `registerGameCache()` helper for templates.

## Contract and invariants

Consumer of OGM-020: copy from OGM-020 `packages/contracts/{bridge,game,input}.ts`; do not redefine. The pieces this ticket consumes, as T04 §4 states them:

```ts
| Envelope<'hello', { protocol: number; capabilities: string[]; mode: 'play' | 'edit' | 'test'; build: 'draft' | 'test' | 'published'; playerIndex: number; tier?: Tier }>
| Envelope<'input.frame', ActionFrame>                                                // host pad + touch overlay
| Envelope<'viewport', { w: number; h: number; dpr: number; orientation: 'landscape' | 'portrait'; safe: Insets }>
| Envelope<'settings', { mute: boolean; volume: number; textScale: number; reduceMotion: boolean }>
export type ActionFrame = { playerIndex: number; tick: number; source: 'keyboard' | 'pointer' | 'touch' | 'gamepad' | 'network'; actions: Record<string, ActionValue> };
```
T04 §4 rules carried: `hello` by `window.postMessage` with an origin check, the port transferred once, 256 KB cap, 120 msg/s, unknown `t` dropped, role checked before any `design.apply`. Host attributes T04 requires: `sandbox="allow-scripts allow-same-origin allow-pointer-lock"`, `allow="autoplay; fullscreen; gamepad"`.

Owner (this ticket, "host frame API"): `createGameFrame(opts: GameFrameOptions): GameFrame` as sketched in the plan U1; additive changes only after merge.

Invariants: no message leaves for the iframe before `ready` except `hello`; `playerIndex` on every outbound frame is the host's value; the overlay never covers the canvas with a hit-testable surface; the iframe is removed and the port closed on `dispose()`.

## Failure, security, migration and accessibility cases

- A game that never sends `ready` within 30 s → `onError({code:'ready-timeout'})`; the app shows its own message.
- Rate or size breach → the bridge drops and counts; 10 breaches in 10 s → `onError({code:'bridge-abuse'})` and the frame is disposed.
- `allow-same-origin` is safe only because the games origin carries no cookies (OGM-007) and is cross-site to the app; the constructor refuses an equal origin and the plan documents why `sandbox="allow-scripts"` alone (opaque origin) is not used (the game's `localStorage` tier memory and the cache worker need a real origin).
- The manifest's strings are rendered as text (`textContent`), never HTML (A4 §4 rule 3).
- No secrets reach the iframe: `hello` carries no identity; `save.write` identity is filled by the app, not here.
- Accessibility: overlay controls carry `aria-label` from the action id, 64 px primary targets, no hover-only affordance; `reduceMotion` forwarded; no migrations.
