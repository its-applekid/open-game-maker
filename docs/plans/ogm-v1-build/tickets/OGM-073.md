## Outcome

`/games` lists the signed-in member's real games as tiles with a spotlight for the selected one (title, tags, version list, Play and Edit), tiles that are building show the job's friendly state and progress, a keyboard or controller moves the selection and opens Play/Edit, and New game is the one fixed 64 px action.

## Context and evidence

The prototype's library (spotlight on top, edge-to-edge tiles, FLIP glides, canvas covers from sprite sheets) is the design reference and is replaced, not ported (E09-2, T09 §3 "Library spotlight"). Covers come from builds' stills, not from a client-side renderer (T09 §5 W4 "must not absorb"). Game rows and the games API are OGM-012's; the job list and friendly states are OGM-010/OGM-013/OGM-032's (T01 §4, T02 §4 projection); branch lists are OGM-043's and arrive later, so the card shows `main` alone until then (T08 §4 `Branch`, D-BRANCH-BASE). Keyboard browsing is this ticket's; controllers work through OGM-071's poller, which turns pad input into synthetic arrow and Enter keys (E09-14), so no coupling is needed. Phone rules: `svh` spotlight, landscape-phone layout, hover affordances gated, 64 px primary targets (E09-7).

## Scope

- `src/routes/games/`: `/games` (`chrome: 'app'`, `auth: 'required'`), with `?spotlight=<gameId>` selecting a game on load (OGM-074 navigates here after admission).
- Data: `GET /api/v1/games` (OGM-012) through TanStack Query; `GET /api/v1/jobs?state=active` (OGM-010 contract, OGM-013 implementation) polled every 10 s while any job is active; `GET /api/v1/games/:g/branches` (OGM-043) when present, else `[main]`.
- Tiles: cover still from the game's latest tested build (`coverUrl` when the API provides it; a generated placeholder with the title and the family colour otherwise), title, up to four genre/vibe icons, a building chip with the friendly state and percent, a "New" badge when no release exists.
- Spotlight: title, tagline, tags, version list (branch names with the active one marked), Play (64 px) and Edit (64 px), Close; Play opens `/g/:gameId?v=<branchId>&mode=play`, Edit `?mode=edit` (OGM-075's route; the placeholder until then).
- Browsing: roving tabindex over the tile grid with arrow keys (2D by measured columns), Enter selects, Enter again opens Play, Escape closes the spotlight; FLIP glide on reorder unless reduced motion.
- New game: a fixed glass button bottom-right → `/new`.
- `registerTestApi('games', { selected, tiles })` for e2e.

## Contract and invariants

**Consumed from OGM-012 (games API; copy from its `packages/contracts/api.ts` at pickup, do not redefine).** This ticket's expectation, drawn from R6/R37/R90 fields the API must carry: `Game { id; title; ownerId; familyId; repo: { owner; name; visibility: 'public'|'private' } | null; coverUrl?: string; publishedReleaseId?: string | null; createdAt; updatedAt }`, `GET /api/v1/games → Game[]` scoped by `authorize()` to the member's games.
**Consumed from OGM-010/OGM-013 (jobs API, T01 §4 verbatim fields).** `GET /api/v1/jobs?gameId=…` rows carry `state` (`queued|admitted|filed|running|paused_budget|done|failed|cancelled`), `kind`, and the projection words from T02 §4: "Waiting for robot capacity", "Building", "Running final tests", "Fixing a problem", "Ready to try", "Out of budget"; the picker renders `job.friendlyState` and `job.progressPercent` when present.
**Consumed from OGM-040/OGM-043 (T08 §4, verbatim).**
```ts
export type Branch = {
  id: string; gameId: string; name: string;           // "Spooky monsters"; main is name:'main'
  gitRef: string;                                     // 'main' | `branch/${id}`
  forkPoint: { parentBranchId: string; parentRev: number; gitSha: string } | null;  // null on main
  headRev: number; latestBuildId: string | null;
  status: 'active' | 'archived' | 'merged'; createdBy: string; createdAt: string;
};
```
Invariants: the picker never writes; a 404 on branches or jobs degrades to `main` and no chip; selection state lives in the URL (`?spotlight=`) so refresh and back work; Play/Edit are disabled while the game has no tested build.

## Failure, security, migration and accessibility cases

- API 401 → `RequireSession` redirect (OGM-070/072); 5xx → one retry line in place of the grid, tiles cached by TanStack Query stay visible.
- Covers are `<img>` from signed blob URLs (OGM-005) or the placeholder; no HTML from the API is ever injected (titles are text nodes).
- Tiles are `<button>`s with `aria-label` "<title>: <tagline>"; the grid is `role="grid"` with roving tabindex; the spotlight is `aria-live="polite"`; focus returns to the tile on close; 64 px Play/Edit/New game, 44 px Close; reduced motion disables glides.
- No migration.
