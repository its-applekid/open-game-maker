## Scope

- `packages/aiur-client` (`@ogm/aiur-client`): the `AiurClient` interface below, implemented over `fetch` with zod schemas for every versioned response (`aiur.ticket_usage` v1, `aiur.ticket_progress` v1, `aiur.usage.accounts` v1, `aiur.control.call` v1) and hand-written schemas for `/api/v1/:issue`, `/api/v1/state`, cancel, messages and event records.
- Every write sends `Authorization: Bearer <token>`, `Origin: <baseUrl>`, `X-Aiur-Request: 1`; typed errors carry aiur's `error.code` (`ticket_not_found`, `spend_cap_exhausted`, `agent_not_running`, `usage_unavailable`, …) and the HTTP status.
- An `events:feed` subscriber: `POST /api/v1/events/token` → Phoenix WebSocket at `/events` → channel `events:feed` with `after` and `patterns`; re-tokens before the 300 s expiry; surfaces `reset` and `error` records; reconnects with backoff.
- Extensions beyond T02 §4 (needed by E06-15 and OGM-032/033): `decisions()`, `decision(id)`, `decide(id, …)` on the supervisor token; `eventsToken()`; `healthz()`.
- The C0 spike: a scratch repo outside this repository, `tracker.kind: memory`, `agent.priority: [fake]`, one daemon under `aiurdev run`; measure issue→claim latency, cancel confirmation time, a spend-cap trip; try committed `.codex/skills` links; write `evidence/T02-spike.md`.

## Contract and invariants

Producer. From T02 §4, verbatim:

```ts
type AiurDaemon = { baseUrl: string; token: string /* write scope */; supervisorToken?: string };
interface AiurClient {
  issue(id: string): Promise<IssueEntry>;                       // GET /api/v1/:id
  usage(id: string): Promise<TicketUsage>;                      // contract aiur.ticket_usage v1
  progress(id: string, limit?: number): Promise<TicketProgress>;// contract aiur.ticket_progress v1
  setSpendCap(id: string, usd: string): Promise<SpendCap>;      // PUT /:id/spend-cap {amount,currency:"USD"}
  cancel(id: string): Promise<{ process: { status: "exited" | "still_running" | "kill_failed" | "generation_changed" } }>;
  pause(id: string): Promise<void>; resume(id: string): Promise<void>;
  message(id: string, text: string, messageId?: string): Promise<{ request_id: string }>;
  nudgeTodo(ids: string[]): Promise<void>;                      // POST /api/v1/control todo([...], only: true)
  accounts(): Promise<UsageAccounts>;                           // GET /api/v1/usage/accounts
  events(after: number, limit: number, patterns: string[]): Promise<EventPage>; // GET /api/v1/events
}
// every write: headers { Authorization: `Bearer ${token}`, Origin: baseUrl, "X-Aiur-Request": "1" }
```

Invariants: `usd` is a decimal string with at most 6 fraction digits (aiur rejects otherwise); `nudgeTodo` posts `{"contract":"aiur.control.call","contract_version":1,"expression":"todo([\"<n>\"], only: true)","max_scope":"write"}`; a 409 from `cancel` is returned, not thrown; `contract_version` mismatches throw `AiurContractError`; the client never logs the token; the client never retries writes except `message` with the same `messageId`.

## Failure, security, migration and accessibility cases

Daemon down: `fetch` errors become `AiurUnavailableError` with the daemon `baseUrl`, never a retry storm (caller decides). Feed: `auth_expiring` triggers a re-token; `reset` records are passed up so OGM-032 re-reads from `head_seq`; `feature_disabled` means `events.export.enabled` is false in that daemon's config (OGM-034 renders it true). Tokens live only in the process env (`packages/config` names `AIUR_API_TOKEN_<slug>` or the per-daemon record from OGM-034); the spike's token is redacted from fixtures. No migrations, no UI.
