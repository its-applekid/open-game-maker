## Outcome

A signed-in creator on a phone taps New game, picks genre, vibe, style family (from the catalog, with pack thumbnails), world, players and point of view (filtered by family and genre), types or dictates "Other" where a tile does not fit, talks the scope through with the builder by text, dictation or voice (when a key exists), attaches a photo of a drawing, and ends with an admitted job; when today's allowance does not cover it, the four offers appear as choices and the chosen one completes the request.

## Context and evidence

The prototype's wizard and scripted "talk it through" are the design reference (E09-6, E06-19) and are replaced. Style families and the views per family come from `style-families.json` through `GET /api/catalog/style-families` (E05-15, T05 §4, OGM-066); the point-of-view list is T04's `ViewId`. There is no zero-spend LLM outside the coding agents, so the text scope chat runs inside a short aiur "scope" ticket whose worker talks through aiur messages (E06-17, D-VOICE-ZERO, OGM-088); dictation is the browser Web Speech API with push-to-talk and review-before-send (E06-11, OGM-083); two-way voice is wired behind the `voice.conversation` capability and turns on only with a key (D-VOICE-ZERO, GATE-PROVIDER-KEY). Admission is deterministic backend code: `POST /api/v1/jobs` answers 202 or 402 with the four offers (E01-12, T01 §4, OGM-013); this screen renders the offers and never estimates. Image upload accepts any image; EXIF is stripped server-side, never relied on client-side (R25).

## Scope

- `src/routes/new/`: `/new?step=genre|vibe|family|world|players|view|talk` with dots, Back/Next/Skip, option tiles (`aria-pressed`, pick limits), the "Other" tile flipping to type or dictate, and a summary chip row on the talk step.
- Options: genre, vibe and world lists carried from `prototypes/studio-v0/data.js` `STEPS` into `src/routes/new/options.ts`; families and their `views` from the catalog; players `solo | multi` (room size later, OGM-078); point of view filtered to the family's `views` and the genre's defaults; "Other" on every step.
- Game creation: `POST /api/v1/games { title?, visibility, choices }` (OGM-012) with `visibility` defaulting to OGM-072's stored pick and forced `private` when the chosen family's packs include a `LicenseRef-*` (paid) licence as reported by the catalog.
- `src/features/scope-chat/`: two-sided panel (you / builder) with captions, a text composer, push-to-talk dictation with review-before-send from `@ogm/voice-client` (OGM-083), a voice mode button present only when `caps.voice.conversation` is true (client from OGM-083, token from `POST /api/voice/token`), image attach (downscale ≤ 2048 px, upload to the scope session's image route), and the session transport from OGM-088 (create session, post message, SSE replies, agreed plan).
- Finish: `POST /api/v1/jobs` (T01 §4 shape) with `kind: 'new_game'`, the agreed `plan`, `start: 'now'`, `idempotencyKey: 'scope:<sessionId>:<n>'`; 202 → `/games?spotlight=<gameId>`; 402 → the offers rendered as four choice cards: trim and split post a message to the scope session and wait for a revised plan, queue re-posts with `start: 'at_reset'`, ask an admin shows `remainingMicroUsd`/`resetsAt` in the friendly unit and polls `GET /api/v1/budget/status`.
- `registerTestApi('new', { step, picks, sessionId })`.

## Contract and invariants

**Consumed from OGM-013 (T01 §4, verbatim).**
```http
POST /api/v1/jobs
{ "gameId": "g_01J…", "branchId": "main", "kind": "new_game"|"feature"|"repair", "complexity": 1-5,
  "plan": { "title": "...", "summary": "...", "scope": {"included": [], "excluded": []}, "tickets": [ {"key": "...", "skills": [], "dependsOn": [], "acceptanceCriteria": []} ] },
  "start": "now"|"at_reset", "idempotencyKey": "fork:…|voice:<sessionId>:<n>" }
→ 202 { "jobId": "j_…", "state": "queued"|"admitted", "reservation": {"amountMicroUsd": 3000000, "sizeClass": "medium", "confidence": "low"}, "slot": "edit", "position": 2 }
→ 402 { "error": "allowance_exceeded", "remainingMicroUsd": 1200000, "resetsAt": "2026-11-01T07:00:00Z", "offers": ["trim","split","queue","ask_admin"] }
```
`GET /api/v1/budget/status?userId=… → { "remainingMicroUsd", "remainingPercent", "unitLabel", "resetsAt", "freeSlots": {"new_game":1,"edit":2}, "queued": [jobId…] }`.
**Consumed from OGM-066 (T09 §4 / T05 §4, verbatim).** `GET /api/catalog/style-families` → `[{ id, label, packs: [{id, name, thumbnailUrl}], views: PointOfView[], genres }]`; `style-families.json`: `[{id, dimension: '2d'|'3d', fidelity, packs: {primary: [], extras: []}, views: PovId[], license_note, coverage: {...}}]`. `PovId`/`ViewId` (T04 §4): `'iso' | 'topdown' | 'side' | 'follow' | 'fps' | 'orbit' | 'fixed'`.
**Consumed from OGM-088 (copy from its `services/api/src/scope/routes.ts`; do not redefine).** This ticket's expectation from T06 E06-10/E06-17 and T06 §4 `VoiceTarget { kind: "scope"; game_id; session_id; creator_id }`: create a session for a game with the choices; post creator text (or a dictated final transcript, or an image reference); an SSE stream of builder replies and a terminal `scope.agreed` carrying the T01 `plan`; trim/split are ordinary messages. The client holds all of it in `src/features/scope-chat/transport.ts` so a route rename touches one file.
**Consumed from OGM-083.** `startDictation({ onPartial, onFinal }): () => void` with review-before-send in the composer; `createVoiceClient({ url, token })` typed from `@aiur/contracts` `VoiceConverseFrame`.
Invariants: the client never computes cost; no offer is auto-chosen; the plan sent to admission is the one the scope session returned (not edited client-side); a `LicenseRef-*` family forces `visibility: 'private'` and the tile says so; "Other" text is sent as a `choices.<step>.other` string.

## Failure, security, migration and accessibility cases

- Catalog 5xx → the family step shows a retry; no hand-written family list exists in the client (R20: families come from the catalog). Scope session 404 (OGM-088 not running) → the talk step shows the summary and a disabled Finish with a one-line reason.
- 402 with an unknown offer id → ignored; with none → treated as "ask an admin".
- Images: client downscale is a size measure, not the privacy measure; the server strips EXIF (R25); only image MIME types are accepted; 10 MB cap client-side.
- Dictation audio goes to the browser vendor (E06-11); a one-line notice sits in settings (OGM-079), not here; nothing is recorded by the app.
- Tiles are 64 px primary targets with `aria-pressed`; the dots are an `aria-label`ed progress; captions are `aria-live="polite"`; push-to-talk is a 64 px hold button with keyboard Space equivalent; reduced motion disables tile pops.
- No migration.
