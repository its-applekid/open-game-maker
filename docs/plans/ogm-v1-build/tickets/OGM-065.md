## Outcome

`gm packs tag --kind model --only 'kenney-mini-dungeon'` renders a multi-angle contact sheet per GLB and a collection sheet, scores the C3 vocabulary with local CLIP lift-ranking, and writes `measured|tagged` asset cards with `low-confidence` flags where due; `gm packs tag --kind audio|map` runs the existing Python workers through one JSON-lines contract; no network call and no spend happen in any mode, and every worker runs with `nice` and a bounded worker count.

## Context and evidence

Per-asset cards exist only for audio (2,814, CLAP) and maps (2,092, CLIP ViT-L/14); zero 3D/2D asset cards exist, and the paid vision pass C3 §13 step 7 assumed has no approved spend (E05-3). The audio and maps pipelines are tested Python tied to heavy local models (torch CPU, essentia, transformers CLAP, CLIP) in `scripts/audio/.venv`, with no TypeScript equivalent (E05-13, E12-6): keep them as workers, add `--json`. The `tag_maps.py` lift-ranking pattern (label score ÷ library mean) is the model for a sheet tagger. Headless Chromium works on this machine's Intel GPU through ANGLE/EGL (E10-4, D-VERIFY-GPU) and the capture pattern already exists in 13 prototype scripts (E12-9). `processing: local-only` (E05-10, OGM-004/061) gates any non-local model; `vision-input` gates any model analysis (C3 §5).

Resolved already: calibration is a human review of ~30 cards per family (T05 §6 risk 2) and is not a gate for merge; `describe` written here carries `by: model, model: 'clip-vit-large-patch14'` with confidence, never rights; status defaults for search already include `measured` (OGM-060).

## Scope

- `gm packs tag --kind audio|map|model|sprite [--only <glob>] [--workers N] [--limit N] [--json]`: dispatches to the worker for the kind, streams its JSON lines, validates every written card with `@ogm/contracts`, updates collection `counts`, emits `packs.tag` events; refuses (exit 2) when the collection's effective rights lack `vision-input`; runs each worker under `nice -n 10` with `--workers` capped at `min(N, cores/3)` (R86); never passes a provider key or network flag.
- Tagger worker contract (T05 §4): `scripts/py/audio/.venv/bin/python -I <script> --json` prints one JSON line per card `{"card": "<path>", "status": "measured|tagged", "flags": [...]}`; non-zero exit on schema failure.
- `scripts/py/audio/{analyze,build_audio_cards}.py` and `scripts/py/maps/tag_maps.py`: add `--json` (the per-card lines above, summaries stay on stderr); no change to measurements, labels or card content; tests stay green.
- `packages/asset-previews` (`@ogm/asset-previews`): `renderSheet(glb, out)` (Playwright + system Chromium on `--use-angle=gl-egl --enable-gpu --ignore-gpu-blocklist`, `GM_VERIFY_SOFTWARE_GL=1` → SwiftShader; three.js r186 in a bundled page; six views: front, back, left, three-quarter, top, close-up; neutral grey background; label strip), `renderCollectionSheet(ids, out)` (grid of thumbs, ≤ 48 per sheet), `spriteSheet(png, out)` (sharp, nearest-neighbour 3× for pixel art); outputs as WebP bucket keys under `assets-local/previews/` or `private/previews/` by rights; at most 2 concurrent browser contexts (D-VERIFY-GPU).
- `scripts/py/tag/tag_sheets.py` (new, in the audio venv): CLIP ViT-L/14 zero-shot over the sheet for each vocabulary group (`environments`, `settings`, `roles`, `materials`, `condition`, `moods` for VFX only), lift-ranked against the whole run (the `tag_maps.py` pattern), filename seeds kept and boosted, `objects` from filename nouns only (no CLIP invention), `confidence` per group, `low-confidence` under 0.6, `proposed_tags` never (enum-only), writes `describe` with model provenance and sets `status: tagged` when description/objects/roles exist else `measured`; measured facts come from the card (OGM-064).

## Contract and invariants

Tagger worker contract (producer T05; consumers `gm packs tag`, OGM-079 intake reports), quoted from T05 §4:

> `scripts/audio/.venv/bin/python -I <script> --json` prints one JSON line per card: `{"card": "<path>", "status": "measured|tagged", "flags": [...]}`; non-zero exit on schema failure.

```ts
// packages/asset-previews/src/index.ts
export function renderSheet(glb: string, out: string, o?: { views?: View[]; size?: number; label?: string }): Promise<{ key: string; width: number; height: number }>;
export function renderCollectionSheet(thumbs: { id: string; file: string }[], out: string): Promise<{ key: string }>;
export function spriteSheet(png: string, out: string, o?: { scale?: 1 | 2 | 3 }): Promise<{ key: string }>;
export type View = 'front' | 'back' | 'left' | 'three-quarter' | 'top' | 'close';
```

Invariants: no worker receives a network-capable flag or any provider key (the command passes a scrubbed env: `PATH`, `HOME`, `OGM_ASSETS_ROOT`, `GM_EVENTS_FILE`); `rights` and `license` are never written by any tagger (OGM-004's `no-model-rights` check runs on every card after tagging); locked fields are skipped (C3 §6); a card whose collection lacks `vision-input` or has `processing: local-only` with a non-local model requested is skipped with the reason (only local models exist, so the second branch is a guard with a test); previews of `redistribution: none` collections go under `private/`.

## Acceptance and verification

### Agent gate
- Python: the existing 40 tests still pass; new tests prove `--json` lines parse and carry `card|status|flags` for each script; `tag_sheets.py` tests prove the status rule (description+objects+roles → `tagged`, else `measured`), the `low-confidence` threshold, enum-only tags, and that `rights` is never in the output card diff.
- `pnpm --filter @ogm/asset-previews test`: with `GM_PREVIEWS_BROWSER=1` on this machine, the orc renders a 6-view WebP sheet whose centre pixels are not background, the renderer string is logged (ANGLE or SwiftShader), and `GM_VERIFY_SOFTWARE_GL=1` still produces a sheet; without the flag, the stub path exercises key placement (`previews/` vs `private/previews/`).
- `pnpm --filter @ogm/gm-cli test -- tag`: a collection without `vision-input` is refused with exit 2; the worker is spawned under `nice`; a worker JSON line with an invalid card fails the run naming the card; `--workers 32` is clamped and reported.
- On this machine: `gm packs tag --kind model --only 'kenney-mini-dungeon' --json` yields ≥ 30 `measured|tagged` lines and `gm assets search orc --kind model/character` returns the orc with a `tagged` status.
### At-merge gate
- `ci / required` green on current main (Python tests run on this host and in OGM-009's venv-free job only where no model is needed; the PR names which ran where).
### Human or e2e evidence
- Kevin reviews one calibration sheet of 30 Mini Dungeon cards (ids, sheet, tags) attached to the PR; disagreements are recorded as locked human edits, not as a merge blocker.

## Failure, security, migration and accessibility cases

Workers run with a scrubbed environment and no network flags; model weights are the ones already cached in the audio venv (no download in tests; a missing model fails with the exact cache path named); the Chromium renderer runs with `--no-sandbox` only if required by the host, documented, and never on user-supplied HTML; a crash mid-run leaves cards untouched (write to `.part` then rename, as `tag_maps.py` does); CPU is bounded by `nice` and `--workers`; private previews never leave `assets-local/private/`. No migration; no UI.
