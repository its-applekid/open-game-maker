## Outcome

`@ogm/blob-store` stores bytes content-addressed under `$OGM_BLOB_ROOT/blobs/sha256/<hex>` with a mime sidecar, returns the same `AssetRef` for the same bytes no matter how often they are put, mints day-rounded HMAC-signed GET URLs on `$OGM_PUBLIC_ORIGIN/blobs/sha256/<hex>?exp=&sig=`, verifies them in constant time, serves a blob as an immutable response through a framework-agnostic handler, and garbage-collects only blobs that are absent from a caller-supplied roots list and older than a grace period; property tests cover each of these.

## Context and evidence

Nothing S3-shaped is installed or startable without sudo (E05-4, E11-8); 2.8 TB is free on the one NVMe; D-BUCKET reads A8's "S3-compatible" as "S3-shaped interface": B6 §6's `BlobStore { put, head, signedGet, delete }` with `blobs/sha256/<hex>` keys and day-rounded signed URLs, served by the API on 8443. Originals in `assets-local/` are the import source and never move. Every tested build artifact is kept (E08-20, D-ARTIFACTS), so GC is driven by an explicit roots list, never by age alone. Resolved: one namespace (`blobs/sha256/`) in V1; previews and private media are blobs with their own mime; the S3 adapter is a second implementation of the same interface later; the HTTP route is mounted by the API lane, this ticket ships the handler.

## Contract and invariants

BlobStore and signed URL (owner: this ticket; consumers OGM-010/080/045/063/064/067/087/008):

```ts
// packages/blob-store/src/index.ts
export type BlobHash = `sha256:${string}`;                       // 64 lowercase hex
export type AssetRef = { hash: BlobHash; bytes: number; mime: string };
export type SignedGet = { url: string; expiresAt: string };      // ISO; exp = next UTC midnight after `expiresAt` + 24 h
export interface BlobStore {
  put(bytes: Uint8Array | AsyncIterable<Uint8Array>, mime: string): Promise<AssetRef>;  // idempotent; first mime wins
  head(hash: BlobHash): Promise<AssetRef | null>;
  signedGet(hash: BlobHash, expiresAt: Date): Promise<SignedGet>;
  delete(hash: BlobHash): Promise<void>;                          // GC and erasure only
  open(hash: BlobHash): Promise<{ ref: AssetRef; stream: NodeJS.ReadableStream } | null>;
}
export class FsBlobStore implements BlobStore {
  constructor(opts: { root: string; signingKey: string; publicOrigin: string; pathPrefix?: string }); // prefix default '/blobs'
}
export function blobPath(root: string, hash: BlobHash): string;   // <root>/blobs/sha256/<hex>
export function roundExpiry(expiresAt: Date): number;             // unix seconds
export function signBlobUrl(key: string, hash: BlobHash, exp: number): string;   // hex HMAC-SHA256 over `${hash}\n${exp}`
export function verifySignedGet(key: string, q: { hash: BlobHash; exp: number; sig: string }, nowMs?: number): { ok: true } | { ok: false; reason: 'expired' | 'bad-signature' | 'bad-hash' };
export function parseBlobRequest(url: URL, pathPrefix?: string): { hash: BlobHash; exp: number; sig: string } | null;
export async function serveBlob(store: BlobStore, key: string, url: URL, nowMs?: number):
  Promise<{ status: 200 | 403 | 404; headers: Record<string, string>; stream?: NodeJS.ReadableStream }>;
  // 200: Content-Type, Content-Length, Cache-Control: public, max-age=31536000, immutable, ETag "<hex>", X-Content-Type-Options: nosniff
export async function gc(store: FsBlobStore, roots: Iterable<BlobHash> | AsyncIterable<BlobHash>, opts: { graceMs: number; nowMs?: number; dryRun?: boolean }):
  Promise<{ scanned: number; kept: number; deleted: BlobHash[] }>;
```

Wire shape: `GET <publicOrigin>/blobs/sha256/<hex>?exp=<unix>&sig=<hex>` (T11 §4). Invariants: `put` of identical bytes returns an identical `AssetRef` and writes nothing the second time; no listing endpoint exists; a blob is never overwritten; `delete` is called only by `gc` or an erasure flow; `gc` never deletes a hash in `roots` and never deletes anything newer than `graceMs`; the signing key is read by the caller from `@ogm/config` (`OGM_BLOB_SIGNING_KEY`) and never logged.

## Acceptance and verification

- `pnpm --filter @ogm/blob-store test`: property tests (fast-check, ≥200 runs each) prove `put` idempotence and hash correctness against `crypto.createHash('sha256')`, that any single-character change to `sig` or `exp` fails verification, that an expired `exp` fails, that `roundExpiry` is a UTC midnight plus 24 h and monotone, that `gc` deletes exactly the non-root blobs older than the grace and nothing in `dryRun`; unit tests cover `serveBlob` status/header matrix, a concurrent double `put` of the same bytes leaving one file, and `tmp/` empty after a failed stream.

## Failure, security, migration and accessibility cases

- Signature comparison uses `crypto.timingSafeEqual` on equal-length buffers; malformed hex or wrong length is `bad-signature` without throwing.
- A crash mid-write leaves only `tmp/<random>`; the next `gc` removes `tmp/` entries older than the grace.
- Mime mismatch on a repeated `put` keeps the stored sidecar (content-addressed; the caller's mime is a hint) and is reported in the returned ref.
- No secret enters this package's logs; `signingKey` is never included in errors.
- Disk full: `put` rejects with the Node error; nothing partial is published (rename never happened).
- No migrations; no UI.
