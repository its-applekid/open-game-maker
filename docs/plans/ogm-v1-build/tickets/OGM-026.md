## Outcome

`@gm/sdk/assets` picks one device tier at startup (`desktop | mobile | low`, overridable with `?tier=`), lowers DPR and effects when 60 frames run slow, and resolves every logical asset id through `assets/manifest.json` to a content-hashed file (with the `low → mobile → desktop` fallback chain), fetching each file once and decoding meshopt GLBs with KTX2 loaded lazily; it never builds a file name itself.

## Context and evidence

- E04-14: `deviceMemory` is missing on iOS, `hardwareConcurrency` is clamped, the GPU string is "Apple GPU"; frame time is the only reliable iPhone signal. Three tiers, DPR caps 2 / 1.5 / 1, drop DPR after 60 frames above 22 ms, remember in `localStorage`, `?tier=` override (C4 §3.2).
- E04-8 and T05 §4: tiers are produced at build time by `gm build assets` (OGM-063) into `assets/manifest.json` (C4 §5.2 shape); the runtime stops editing geometry, uses `setMeshoptDecoder`, lazy `KTX2Loader`, parallel deduped fetches. The manifest type is owned by OGM-020 and shared with OGM-063.
- D-TIERS resolves the C2 §3 "variants at import" contradiction: import never makes variants; the SDK picks a tier once and adapts.
- Tier budgets are untuned (C4 §5.5): the loader reports, `gm verify` (OGM-090) judges.

## Scope

- `pickTier(signals?)`: pure function over `{coarse, iOS, deviceMemory, hardwareConcurrency, dpr, override}`; `readSignals()` fills it from the browser; result remembered under `localStorage['gm.tier']` unless overridden.
- `FrameGovernor`: `observe(frameMs)` per rendered frame; after 60 samples with median > 22 ms steps DPR 2 → 1.5 → 1.25 → 1, then sets `effects: false`; emits `{tier, dpr, effects}` through `onChange`; persists the result.
- `AssetLoader`: `load(manifestUrl)`, `resolve(id) → {url, file, mesh?, bounds?, license}`, `preload(ids)`, `mesh(id)`, `texture(id)`, `audio(id)`; one in-flight promise per file; GLB decode through three's `GLTFLoader` with `MeshoptDecoder`; `KTX2Loader` imported only when a resolved file lists `ktx2` in `decoders`; `attachRenderer(renderer)` for `KTX2Loader.detectSupport`.
- Errors name the id and the tier chain tried; a missing id is a thrown `AssetNotFound`, never a silent placeholder.

## Contract and invariants

Consumer of OGM-020: copy from OGM-020 `packages/contracts/{assets}.ts`; do not redefine. The pieces this ticket consumes, as T04 §4 states them:

```ts
export type Tier = 'desktop' | 'mobile' | 'low';
export type AssetManifest = { version: 1; tiers: Tier[]; files: Record<string, { bytes: number; tris?: number; gpuTexMB?: number; decoders: ('meshopt' | 'draco' | 'ktx2')[] }>;
  assets: Record<string, { file: Partial<Record<Tier | '*', string>>; mesh?: string; bounds?: [number, number, number]; license: { id: string; attribution?: string; use: 'any' | 'personal' | 'inspiration' } }> };
export function pickTier(): Tier;                                        // C4 §3.2 signals + ?tier= override
export interface AssetLoader { preload(ids: string[]): Promise<void>; mesh(id: string): Promise<Mesh>; texture(id: string): Promise<Texture>; audio(id: string): Promise<AudioBuffer> }
```

Invariants: file names come only from `manifest.assets[id].file[tier]` with the chain `low → mobile → desktop → '*'`; the same file is fetched once per loader; `pickTier` is pure given signals; the override wins over the remembered tier; the governor only lowers, never raises, within a session.

## Failure, security, migration and accessibility cases

- A manifest fetch failure or schema mismatch (Zod parse of `AssetManifest`) rejects `load()` with the URL; nothing downstream guesses paths.
- `localStorage` may throw (private mode): every read and write is wrapped; the tier falls back to the computed one.
- A tier listed in `manifest.tiers` but missing for an asset follows the chain; a chain that ends empty throws naming the id.
- No secrets, no migrations, no UI. `reduceMotion` is not this ticket's concern (settings go through the bridge, OGM-028).
