## Scope

- `packages/contracts/src/assets.ts`: append the `AssetsLock` Zod schema and type (quoted below), emit `schemas/assets-lock.v1.json` and `fixtures/assets.lock.json`.
- `gm assets use <id...> [-f picks.txt] [--dest assets/] [--placeholder] [--exception "<reason>"]`: resolves ids in the index; refuses (exit 2, one line, `Try: gm assets why <id>`) when effective rights lack `in-game` (or `placeholder` without `--placeholder`), when `redistribution: none`, when the card is `quarantined`/`rejected`, or when `describe.style_family ∉ {lock.family, 'any'}` and no `--exception` (logged as `assets.family_exception`); copies `source.files[]` (primary + texture + companion) to `<dest>/<kind>/<collection>/<path>.<ext>`, computes sha256, upserts the lock entry, regenerates `CREDITS.md`; `--refresh` re-reads rights for existing entries.
- `gm assets register <path> --made-by-agent [--from <id>...]`: tier-3 entry `t3:<game>/<path>` with `derived_from`, rights = intersection of the sources' effective rights (or CC0-equivalent when none), sha256 of the file.
- `gm assets why <id>`: prints the effective rights and each basis entry (`type  uses  audience  redistribution  set_by  date  note`) in one line each, then the refusal rule that would apply for `in-game`, `placeholder` and `publish public`.
- `gm check assets [--publish] [--repo-visibility public|private] [--json]`: every lock entry exists in the index; file at `path` exists and its sha256 matches; `license`/`rights` equal the index's current effective rights; `in-game` present, or `placeholder` when not `--publish`; with `--publish`: no `placeholder`, no `audience: private` when `--repo-visibility public`, no `redistribution: none`; `family` and `pov` present. Exit 1 with one line per violation `<id>  <rule>  <detail>`; `--json` emits `{allowed, reasons: [{code: 'rights', path, detail}]}` matching `BoundaryVerdict.reasons[]` so OGM-039 can relay it.
- `CREDITS.md`: one line per distinct `attribution`, grouped by licence, generated deterministically.

## Contract and invariants

`assets.lock.json` (producer: this ticket; consumers OGM-039 gate, OGM-045 publish, OGM-048 forks, OGM-063 build, OGM-066 search default, OGM-060 `list`). Quoted verbatim from T05 §4:

```ts
type AssetsLock = { version: 1; family: StyleFamilyId; pov: PovId;
  assets: Array<{ id: string;               // t1:kenney-mini-dungeon/character-orc@2.0 | t3:<game>/boss-door
    sha256: string; path: string;           // path in the game repo
    license: string;                        // SPDX or LicenseRef-*
    rights: { uses: Use[]; audience: 'private'|'public'; redistribution: 'none'|'in-build'|'free'; attribution: string|null };
    derived_from?: string[]; added: string }> };
```

`StyleFamilyId` is the C3 `style_family` enum (`chunky-low-poly | detailed-low-poly | simple-low-poly | pixel-art | flat-cartoon | isometric-2d | sketch | photoreal | any`); `PovId` is `iso | topdown | side | follow | fps | orbit | fixed`; `Use` is the schema's `use` enum. Invariants: entries are sorted by `id`; `rights` is always the effective rights at the time of `use`/`--refresh`, never hand-edited (the check compares against the index); `redistribution: none` never enters a lock; an entry's `path` is relative, inside the repo, never under `node_modules` or `.gm/`; `added` is an ISO date.

Check verdict (`--json`): `{ allowed: boolean; reasons: { code: 'rights'; path?: string; detail: string }[] }`, the `rights` subset of OGM-035's `BoundaryVerdict` (copy from OGM-035 `packages/contracts/src/commit.ts`; do not redefine).

## Failure, security, migration and accessibility cases
