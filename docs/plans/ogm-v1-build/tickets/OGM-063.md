## Outcome

In a game repo with a lockfile, `gm build assets` writes `public/assets/<content-hash>.glb|webp|mp3` files and `public/assets/manifest.json` that parses with OGM-020's `AssetManifestSchema`, carries a licence per asset, and exits 1 with the offending numbers when the mobile tier exceeds the C4 §5.5 budget; a second run with no changes finishes from the cache in under a second.

## Context and evidence

Device tiers happen at game build time, not at pack import (E05-6, D-TIERS): C4 measured 174 GLBs → 4 kit files, 8.6 MB → 0.8 MB. None of C4's tools are installed (`gltf-transform`, `gltfpack`, `toktx` absent; E05-7), so this ticket adds `@gltf-transform/*`, `meshoptimizer` and `sharp` as package dependencies and keeps KTX2 behind `--ktx2` that errors when `toktx` is missing. Audio ships as MP3 encoded at build time because Ogg Vorbis was silent on iPhone (E05-17; ffmpeg 7.1.5 present). Netlify sends GLB/BIN uncompressed, so compression must be inside the files (T05 §7). The manifest type is owned by OGM-020 (`packages/contracts/{assets}.ts`, T04 §4) and the SDK loader (OGM-026) never derives file names (E04-14, R45).

Resolved already: the lockfile (OGM-062) is the input and the licence source; `source` provenance stays in the lockfile and is not duplicated into the manifest (the T04 type has no `source` key); `variants[]` on cards is unused in V1 (E05-6).

## Scope

- `gm build assets [--tier desktop,mobile,low] [--budget mobile] [--out public/assets] [--ktx2] [--json]`: reads `assets.lock.json`, resolves each entry's file(s) in the repo, builds per kind: kit models (`model/kit`, and any `model` under 5k triangles in a collection with a shared colormap) merged into one GLB per collection (dedup, prune, weld, bake transforms, snap UVs to the colormap texel, quantize, meshopt; one named mesh per asset; `bounds` in `mesh.extras`); high-poly models per tier (simplify ratio 1 / 0.5 / 0.25, texture size 2048 / 1024 / 512, WebP, meshopt; skinned models keep nodes and rigs); images/sprites/UI → WebP (lossless for pixel art, `pixel_art` from the card); audio → MP3 (`-codec:a libmp3lame -q:a 4` with `loudnorm`, loop-friendly trimming off); fonts copied; licence written into each GLB's `asset.extras.license`.
- Content-hashed output names `<slug>.<tier>.<hash8>.<ext>` (`*` tier for shared files); cache under `.gm/cache/assets/<sourceSha>-<recipeHash>/` so unchanged inputs are reused.
- `public/assets/manifest.json` conforming to OGM-020's `AssetManifest`; `license.use` mapped from lock rights (`public` + `free|in-build` → `any`; `private` → `personal`; never `inspiration` in a lock).
- Budget report (`bytes`, `tris`, `gpuTexMB`, request count per tier) and `--budget mobile` gate: first-view download ≤ 2 MB, ≤ 30 files, no texture above 1024, `gpuTexMB` ≤ 100, visible tris ≤ 300k (sum over the manifest's `tris`); exit 1 listing each exceeded number; `gm verify` (OGM-090) reads the same report.
- Emits `assets.build` events (R88).

## Contract and invariants

Consumed from OGM-020 `packages/contracts/src/assets.ts`; copied here from T04 §4 so the agent builds against it, do not redefine:

```ts
export type Tier = 'desktop' | 'mobile' | 'low';
export type AssetManifest = { version: 1; tiers: Tier[]; files: Record<string, { bytes: number; tris?: number; gpuTexMB?: number; decoders: ('meshopt' | 'draco' | 'ktx2')[] }>;
  assets: Record<string, { file: Partial<Record<Tier | '*', string>>; mesh?: string; bounds?: [number, number, number]; license: { id: string; attribution?: string; use: 'any' | 'personal' | 'inspiration' } }> };
```

Build manifest producer rules (T05 §4): content-hashed file names; every `assets.<id>.file` resolves for every tier in `tiers` (directly or through `*`); `files[name].bytes` equals the written size; `decoders` lists `meshopt` for every meshopt-compressed GLB and `ktx2` only when `--ktx2`; asset ids equal lockfile ids; `license.id` equals the lock entry's `license`. Invariants: deterministic output for identical inputs and recipe (hash names stable across runs); the build never reads `assets-local/` (only files already in the repo); `gm check assets` must pass before building.

Budget report (producer; consumer OGM-090 verify report):

```ts
export type AssetBudgetReport = { tier: Tier; bytes: number; files: number; tris: number; gpuTexMB: number; maxTexture: number; exceeded: { metric: string; value: number; limit: number }[] };
```

## Refreshable implementation notes

Create `packages/gm-cli/src/commands/build/assets/index.ts` (the command), `plan.ts` (lock → build jobs grouped by collection and kind), `kit.ts` (`@gltf-transform/core` `Document` merge per collection: `dedup`, `prune`, `weld`, `flatten`, `join` per asset, `quantize`, `meshopt` via `meshoptimizer` encoder, name each mesh by asset id, `extras.bounds`), `model.ts` (`simplify` with `meshoptimizer`, `textureCompress` → `sharp` WebP, `resample`, `quantize`, `meshopt`; `--instance false --join false` for skinned), `image.ts` (sharp WebP, lossless when `pixel_art`), `audio.ts` (`execFile('ffmpeg', ...)` MP3), `font.ts`, `manifest.ts` (build and validate with `AssetManifestSchema.parse`), `budget.ts`, `cache.ts` (key = sha256(source bytes) + sha256(JSON recipe + tool versions)). Fixtures: two tiny Kenney-style GLBs with a shared 16×16 colormap, one 10k-tri GLB, one PNG, one WAV, built into `test/fixtures/game/` with a lock. Commands: `pnpm --filter @ogm/gm-cli test`, `pnpm --filter @ogm/gm-cli build`, then on a real game repo `gm build assets --json`. Refreshable against 9508c1c.

## Failure, security, migration and accessibility cases

The build runs inside the per-job sandbox (D-SBX): no network, writes only under `public/assets/` and `.gm/cache/`; a corrupt GLB fails that asset with its id and the glTF Transform error, not the whole build, unless `--strict`; ffmpeg is invoked with `execFile` and an argument array (no shell); output names are hashes, never source paths, so private pack layout never leaks into the shipped game; no migration; no UI.

## Surfaces

- Reads: `assets.lock.json`, `assets/**` (the repo copies), `packages/contracts` (`AssetManifest`).  - Writes: `packages/gm-cli/src/commands/build/assets/*` (from build-order.json); in a game repo `public/assets/**`, `.gm/cache/assets/**`.  - Contracts: none declared; produces the manifest instance of OGM-020's type and the budget report OGM-090 reads.
