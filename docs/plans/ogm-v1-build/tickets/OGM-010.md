## Context and evidence

No backend code exists at 9508c1c (E01-1): there is no TypeScript file in the repository, so everything here is new. E01-2 and E11-9 fix the store: no Postgres, no `sqlite3` CLI, `node:sqlite` experimental, `better-sqlite3` in the npx cache; D-DB chose SQLite in WAL mode owned by the single API process through Drizzle, with Postgres a driver swap later. D-API chose REST over Hono with Zod schemas from `packages/contracts` because non-TS callers exist (aiur hooks via curl, the Elixir voice host, the rooms service). T12's hot-write-surface table is why routes are mounted by directory scan and migrations are timestamped files: eleven tickets write into `services/api` in parallel. Contradictions already resolved: A7 R07 advisory locks (not needed with one writer, E01-2); tRPC (rejected, D-API); `node:sqlite` (rejected while experimental, risk 7 in T01 §6).

## Scope

- `services/api` (`@ogm/api`): Hono app factory, `@hono/node-server` bound to `127.0.0.1`, `/healthz`, request id, JSON error envelope, Zod validation helper, route scanner over `src/<context>/routes.ts`, principal seam (`Principal` type, service-token resolver, job-token sign/verify, resolver registry), typed in-process event bus, `main.ts` entrypoint that reads env through `packages/config`.
- `packages/db` (`@ogm/db`): `openDb()` (better-sqlite3, `PRAGMA journal_mode=WAL`, `foreign_keys=ON`, `busy_timeout=5000`), Drizzle instance, `migrate()`, schema barrel `src/schema/index.ts` (append-only, one file per context), migrations folder `migrations/<YYYYMMDDHHmmss>_<name>.sql`, first migration `app_meta`.
- `packages/contracts`: `src/api.ts`, `src/jobs.ts`, `src/budget.ts`, `src/analytics.ts`, `src/reports.ts`, `src/notifications.ts` as Zod schemas with inferred types, one fixture per request/response shape under `fixtures/<family>/`, JSON Schema emitted by OGM-004's emit script, six lines appended to the barrel.

- Also creates `packages/health` (the `HealthResponse` contract OGM-004 defines) and mounts `GET /blobs/sha256/:hex` through `packages/blob-store`'s `serveBlob` (OGM-005) so signed blob URLs resolve from the API's loopback port.

## Contract and invariants

T01 §4, quoted verbatim, is the HTTP contract these files encode (the policy block belongs to OGM-012):

```http
POST /api/v1/jobs
{ "gameId": "g_01J…", "branchId": "main", "kind": "new_game"|"feature"|"repair", "complexity": 1-5,
  "plan": { "title": "...", "summary": "...", "scope": {"included": [], "excluded": []}, "tickets": [ {"key": "...", "skills": [], "dependsOn": [], "acceptanceCriteria": []} ] },
  "start": "now"|"at_reset", "idempotencyKey": "fork:…|voice:<sessionId>:<n>" }
→ 202 { "jobId": "j_…", "state": "queued"|"admitted", "reservation": {"amountMicroUsd": 3000000, "sizeClass": "medium", "confidence": "low"}, "slot": "edit", "position": 2 }
→ 402 { "error": "allowance_exceeded", "remainingMicroUsd": 1200000, "resetsAt": "2026-11-01T07:00:00Z", "offers": ["trim","split","queue","ask_admin"] }
```
Job row fields the other tracks read: `aiurRepo`, `aiurIssueNumber`, `aiurSpendCapMicroUsd`, `state`, `pausedReason`, `usageMicroUsd` (reconciled from `GET /api/v1/:issue/usage` `api_equivalent.amount`).
```http
GET  /api/v1/budget/status?userId=…      → { "remainingMicroUsd", "remainingPercent", "unitLabel", "resetsAt", "freeSlots": {"new_game":1,"edit":2}, "queued": [jobId…] }
POST /api/v1/budget/estimate { "gameId", "summary" } → { "sizeClass": "large", "rangeMicroUsd": [4e6, 9e6], "confidence": "low", "fits": false }
POST /api/v1/jobs  (as above, start: "at_reset")
```
```json
POST /api/v1/analytics/events  (bearer: job token or session)
{ "events": [ { "ts": "2026-10-31T09:12:03Z", "gameId": "g_…", "jobId": "j_…", "aiurRunId": "…?", "attemptId": "…?",
   "actor": "agent"|"human", "activity": "asset_pipeline"|"level_building"|"gameplay_code"|"animation_vfx"|"audio"|"ui_hud"|"playtesting"|"deploy_release"|"writing",
   "boundary": "start"|"end"|"point", "source": "gm_cli"|"skill"|"editor"|"sdk"|"manifest_path", "meta": { "command": "gm verify", "system": "combat" } } ] }
```
`meta` keys are allow-listed; no free text beyond a command name. Admin read: `GET /api/v1/admin/builds/:jobId/timeline` merges aiur phases (from usage/telemetry) with OGM activities.
```http
POST /api/v1/reports  { "gameId", "releaseId", "buildHash", "text"?, "error"?: {"type","message","frames":[…]}, "bundleKey": "<private bucket key from T05 signed upload>" }
→ 201 { "reportId", "signature", "route": "game_repair"|"platform"|"editor_hint"|"stored", "jobId"? }
```
Notifications: `POST /api/v1/push/subscriptions { endpoint, keys }`; `GET /api/v1/notifications/stream` (SSE `event: build.done | job.started | intake.report`).

export const Id = z.string().regex(/^[a-z]{1,3}_[0-9a-f-]{36}$/);        // <prefix>_<uuid v4>: u_ f_ g_ j_ r_ n_ i_
export const MicroUsd = z.number().int().nonnegative();                    // api-equivalent micro-dollars (D-BUDGET-UNIT)
export const IsoTime = z.string().datetime({ offset: true });
export const ApiError = z.object({ error: z.string(), message: z.string().optional(), details: z.unknown().optional() });
export type Principal =
  | { kind: 'user'; userId: string; familyId: string; platformRole: 'maintainer'|'admin'|'none'; capability: 'creator'|'player' }
  | { kind: 'job'; jobId: string; gameId: string; familyId: string }

export const JobKind = z.enum(['new_game','feature','repair']);
export const JobState = z.enum(['queued','admitted','filed','running','paused_budget','done','failed','cancelled']);

export const Confidence = z.enum(['low','medium','high']);

  tickets: z.array(z.object({ key: z.string(), skills: z.array(z.string()), dependsOn: z.array(z.string()), acceptanceCriteria: z.array(z.string()) })).min(1).max(12) });

export const CreateJobRequest = z.object({ gameId: Id, branchId: z.string().default('main'), kind: JobKind, complexity: z.number().int().min(1).max(5),
  plan: JobPlan, start: z.enum(['now','at_reset']).default('now'), idempotencyKey: z.string().min(1).max(200).optional() });
export const CreateJobAccepted = z.object({ jobId: Id, state: z.enum(['queued','admitted']), reservation: Reservation, slot: JobSlot, position: z.number().int().nonnegative().optional() });
export const AllowanceExceeded = z.object({ error: z.enum(['allowance_exceeded','platform_cap_reached']), remainingMicroUsd: MicroUsd, resetsAt: IsoTime, offers: z.array(z.enum(['trim','split','queue','ask_admin'])) });
export const Job = z.object({ id: Id, gameId: Id, branchId: z.string(), familyId: Id, creatorId: Id, kind: JobKind, complexity: z.number().int(), state: JobState,
  pausedReason: z.enum(['over_reservation','budget_exhausted','admin']).nullable(), start: z.enum(['now','at_reset']), startAt: IsoTime.nullable(),

  aiurRepo: z.string().nullable(), aiurIssueNumber: z.number().int().nullable(), aiurSpendCapMicroUsd: MicroUsd.nullable(),
  idempotencyKey: z.string().nullable(), createdAt: IsoTime, updatedAt: IsoTime, terminalAt: IsoTime.nullable() });
export const JobStage = z.enum(['waiting_capacity','building','final_tests','fixing','ready','out_of_budget','failed']); // R27 creator words; OGM-032 maps
export const JobTokenClaims = z.object({ jobId: Id, gameId: Id, familyId: Id, exp: z.number().int() });  // bearer "gmj1.<b64url json>.<b64url hmac>"
// packages/contracts/src/budget.ts
export const BudgetStatus = z.object({ remainingMicroUsd: MicroUsd, remainingPercent: z.number().min(0).max(100), unitLabel: z.string(), resetsAt: IsoTime,
  freeSlots: z.object({ new_game: z.number().int(), edit: z.number().int() }), queued: z.array(Id) });
export const EstimateRequest = z.object({ gameId: Id, summary: z.string().min(1).max(2000) });
export const Estimate = z.object({ sizeClass: SizeClass, rangeMicroUsd: z.tuple([MicroUsd, MicroUsd]), confidence: Confidence, fits: z.boolean() });
export const SizeClassRow = z.object({ kind: JobKind, sizeClass: SizeClass, p50MicroUsd: MicroUsd, p80MicroUsd: MicroUsd, samples: z.number().int() });
export const FamilyBudgetSettings = z.object({ familyId: Id, resetZone: z.string(), unitLabel: z.string(), microUsdPerUnit: MicroUsd.positive(),
  platformCapMicroUsd: MicroUsd, slots: z.object({ new_game: z.number().int().min(0), edit: z.number().int().min(0) }), hardCapMultiplier: z.number().positive() });
export const Allowance = z.object({ userId: Id, familyId: Id, dailyMicroUsd: MicroUsd, remainingMicroUsd: MicroUsd, resetsAt: IsoTime });

export const Activity = z.enum(['asset_pipeline','level_building','gameplay_code','animation_vfx','audio','ui_hud','playtesting','deploy_release','writing']);

// packages/contracts/src/reports.ts
export const ReportFrame = z.object({ file: z.string().max(300), line: z.number().int(), col: z.number().int().optional(), fn: z.string().max(120).optional() });

export const ReportRoute = z.enum(['game_repair','platform','editor_hint','stored']);
export const CreateReportResponse = z.object({ reportId: Id, signature: z.string().length(64), route: ReportRoute, jobId: Id.optional() });
export interface IssueWriter { file(input: { title: string; body: string; labels: string[] }): Promise<{ ref: string }> }   // never carries agent:todo

// SSE: GET /api/v1/notifications/stream → "id: <notification id>\nevent: <kind>\ndata: <Notification JSON>"; Last-Event-ID resumes.

## Failure, security, migration and accessibility cases

The DB path `$OGM_DATA_DIR/ogm.sqlite3` is created 0600 under `UMask=0077`; a missing env name aborts startup with the name, never a value (OGM-003 rule). A second process opening the DB is a defect: only `@ogm/api` imports `@ogm/db`'s `openDb`. Service and job tokens compare with `timingSafeEqual`; job tokens expire (default 48 h) and carry no secret. The route scanner ignores anything but `src/<context>/routes.ts` so a stray file cannot mount. Migrations are timestamped SQL files applied in name order and recorded in `app_meta`; never edited after merge. No UI.
