## Contract and invariants

**Route table (T09 §4, verbatim; this ticket owns it).** `/` title · `/age` · `/signin` · `/connect/github` · `/games` · `/new` (steps `?step=`) · `/g/:gameId` (play/edit, `?v=:branchId`, `?mode=play|edit`) · `/g/:gameId/versions` · `/g/:gameId/releases` · `/join/:inviteToken` · `/admin` (`/members`, `/invites`, `/budgets`, `/builds`, `/intake`) · `/settings`. Hashes `#library`, `#new` redirect to `/games`, `/new` (Kevin uses them).

**Screen-module convention (this ticket owns it).**
```ts
// apps/web/src/app/screen.ts
export type ScreenRoute = {
  path: string;                       // one entry from the route table; children for sub-paths (/admin/*)
  element: React.ReactNode;
  chrome: 'bare' | 'app';             // bare: title, age, signin, join; app: logo, bug button, chat dock host
  auth: 'none' | 'required';          // required → redirect to /signin?next=<path> when the session is null
  children?: { path: string; element: React.ReactNode }[];
};
// apps/web/src/routes/<screen>/route.tsx:  export const route: ScreenRoute = { ... };
// apps/web/src/app/router.tsx collects:   import.meta.glob('../routes/*/route.tsx', { eager: true })
```
Invariants: one directory per screen; `router.tsx` is never edited to add a screen; a screen directory owns its components, store slice and tests; shared code lives in `src/lib/*`.

**Test hook (this ticket owns it).**
```ts
// present only when location.search includes 'test'
window.__ogmHost = { version: 1, route(): string, navigate(to: string): void,
  register(name: string, api: object): void, get(name: string): object | undefined, snapshot(): { route: string; registered: string[] } };
```
Screens add their own hooks with `register('games', {...})`; nothing else defines `window.__*` in the app.

**Netlify (T09 §4, verbatim).** `public/_redirects`: `/api/* https://BACKEND_HOST/api/:splat 200` then `/* /index.html 200`. `public/_headers`: noindex until launch, `/sw.js` no-cache, `/town/*` no-cache, `/assets/*` immutable.
Added by D-ORIGIN: `/auth/* https://BACKEND_HOST/auth/:splat 200` before the SPA line. `BACKEND_HOST` is `applekid.tailee0e71.ts.net:8443` (T11 §4 ingress map) written literally; no secret is involved.

## Failure, security, migration and accessibility cases

- A proxied `/api` request that returns HTML (Netlify fallback hit first) means the `_redirects` order is wrong; the unit test guards order. `/auth` must precede `/*` too.
- The SW must never cache `/sw.js`, `/api/*` or `/auth/*` (cross-origin after rewrite they are same-origin paths; exclude by prefix). Deploying without stamping `__BUILD__` leaves phones on an old cache; `deploy.sh` refuses to deploy when the stamp is still literal.
- No secrets: the Netlify site id is already committed in the prototype; the Netlify CLI login lives in the operator's home, never in the repo or CI (R114).
- Tokens: `--tap-primary: 64px`, `--tap-secondary: 44px`, focus-visible outline, `prefers-reduced-motion` kill switch, `color-scheme: dark`.
- No migration.
