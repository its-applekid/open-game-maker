## Outcome

`prototypes/README.md` says what each prototype was and which ticket or package replaced it; `prototypes/studio-v0/README.md` and `prototypes/ui-v0/README.md` start with an "Archived" line pointing at `apps/web`; `apps/web/title-town/` holds the title-city sources and its build tools with history preserved (`git log --follow` works) and `apps/web/title-town/tools/build.sh && node apps/web/title-town/tools/bundle.mjs apps/web/public/town` rebuilds the town bundle `apps/web` serves; `prototypes/studio-v0/tools/deploy.sh` exits 1 with a pointer to `apps/web/tools/deploy.sh`; the live site is unchanged.

## Context and evidence

The three prototypes are throwaway code whose reusable parts are the contracts they proved and the title town as a built asset (E12-2); the town must stay and is served from `public/town/` unbundled by Vite (E09-3, D-LOOK), with OGM-071 porting the host side and copying the built bundle. The studio deploy script holds two behaviours that OGM-070's `apps/web/tools/deploy.sh` reproduces (noindex `_headers`, Synty exclusion, SW build stamp; E12-12), so the old script is retired once the new one deploys. The per-prototype capture scripts are superseded by OGM-090 (`gm run`/`gm shot`/`gm perf`; E12-9, T10 §3) and are frozen, not ported again. `.gitignore` patterns `vendor/`, `models/`, `town/` are unanchored, so the moved directories stay ignored (E12-13); OGM-001 rewrote `.gitignore`, so verify at pickup.

Resolved, do not reopen: `title-city` is throwaway code but not a throwaway artifact; `studio-v0` and `ui-v0` are archived in place, not deleted (history and the C1 write-up refer to them); `_pf.mjs` (untracked CDP driver, E12-16) is never committed.
