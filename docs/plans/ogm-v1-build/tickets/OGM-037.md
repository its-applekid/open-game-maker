## Outcome

`renderAiurConfig({repo, workspaceRoot, denyReadRoots, …})` emits a game-builder `.aiur/config` whose Codex policy has `networkAccess: false`, writable root = that repo's workspace only, no `/tmp`, a dedicated `CODEX_HOME`; `scripts/sandbox/probe.sh` run on this host prints a table showing that sandboxed commands cannot read the E03-9 credential paths (or records exactly which ones they still can); `preflight(daemonDir)` returns `{ok:false}` whenever the file on disk differs from the render.

## Context and evidence

Per-job isolation on this machine is Codex CLI's own bwrap+landlock sandbox driven by aiur's `turn_sandbox_policy`, plus a Codex permission profile that denies reads of credential paths (D-SBX; E03-1, E03-4, E03-13). aiur's own default policy is network-open with `readOnlyAccess: fullAccess` (E03-4; `codex_sandbox_policy.ex:66-83`), and the `.aiur/config` already in this working tree for building the platform is network-open and `bypassPermissions` (E03-10): it must never be the template. Hosted mode cannot be switched on (E03-7, E02-11), so the fail-closed check is OGM's. Resolved: no model proxy (E03-14); no VM or second uid in V1 (E03-3, E03-18); the Codex `deny_read` semantics are [I] until the probe runs (spike S1).

## Scope

- `services/builder/src/policy/render.ts`: `renderAiurConfig(input)` → the full YAML text of a daemon's `.aiur/config` from the T03 §4 template plus the T02 §4 keys (`tracker.github.repo/base_branch/allowed_users/bot_account/identity_mode/human_mergers`, `agent.priority/accounts/max_concurrent_agents/max_agent_duration_minutes/max_dispatches_per_ticket/max_turns_by_complexity/build_nice`, `hooks_file`, `prompt_file`, `events.export.enabled`, `server.host/port`, `workspace.root`, `instance.mode/deployment_kind`, `merge_policy.ci`).
- `services/builder/src/policy/preflight.ts`: `preflight(daemonDir, input)` re-renders and compares the config on disk, and checks the Codex profile file hash; returns reasons, never throws.
- `services/builder/sandbox/profile.toml`: the Codex permission profile with `deny_read` over the E03-9 paths, `assets-local/`, and every other daemon's workspace root (rendered per daemon by `renderCodexProfile`).
- `scripts/sandbox/probe.sh`: spike S1; runs `codex sandbox` with the profile and prints one row per path (readable / denied), one row for network, one for `/tmp`.
- Creates the `services/builder` package (`@ogm/builder`, hosted in the API process; see plan §1) since this is the lane's earliest write there.

- The rendered game-builder config includes `decisions.supervisor_allowed_kinds: ["direction_checkpoint"]` and a per-daemon `AIUR_SUPERVISOR_TOKEN` in its env file, so OGM-082 can answer checkpoint Commands through `/decide`.

## Contract and invariants

Producer. From T03 §4, verbatim:

```yaml
instance: { mode: local, deployment_kind: operator }
agent:
  priority: [codex]
  accounts: { codex: [gamebuilder] }          # CODEX_HOME=~/.config/ogm/codex-gamebuilder
  max_concurrent_agents: 1                     # OGM admission is the real limiter
  max_agent_duration_minutes: 45
  build_nice: 10
  codex:
    approval_policy: on-request
    thread_sandbox: workspace-write
    turn_sandbox_policy:
      type: workspaceWrite
      writableRoots: ["<workspaceRoot>"]       # that repo only; no /tmp
      networkAccess: false
      excludeSlashTmp: true
```

Codex permission profile (T03 §4, verbatim; keys [I] until spike S1): `~/.config/ogm/codex-gamebuilder/config.toml` with `[permissions.gamebuilder.filesystem]` `deny_read = ["~/.config/gh", "~/.aiur/github-budget", "~/.codex/auth.json", "~/.claude", "~/.claude-2", "~/.config/ogm", "~/.config/netlify", "~/.ssh", "~/.aiur/.env", "<repo>/assets-local", "<other workspace roots>"]` and `secret_file` entries for the same.

Invariants: the renderer is deterministic (same input, byte-equal output) and refuses `networkAccess: true`, any `writableRoots` entry outside `workspaceRoot`, `/tmp`, `approval_policy: never`, `permission_mode: bypassPermissions`, or `instance.mode: hosted`; `preflight` compares the parsed YAML of the on-disk file with the render and fails on any difference in the `agent.codex`, `instance`, `workspace`, `tracker.github.repo` or `hooks_file` keys; `renderCodexProfile` never emits a path under `workspaceRoot` into `deny_read`.

## Acceptance and verification

### Agent gate
- `pnpm --filter @ogm/builder test`: render equals the fixture byte-for-byte; each forbidden input (`networkAccess: true`, extra writable root, `/tmp`, `approval_policy: never`, hosted mode) throws; `preflight` passes on the rendered file and fails when any guarded key is edited on disk or the profile hash differs; profile rendering excludes the workspace root.
