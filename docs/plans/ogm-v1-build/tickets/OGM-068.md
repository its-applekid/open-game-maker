## Outcome

On this machine, `gm packs sync kaykit` (and `lpc`, `game-icons`, `fontsource:<font>`) fetches the pinned commit or version, runs the normal import, and the result is searchable as `t2:<source>/<path>@<pin>` with per-item licences (LPC's `CREDITS.csv` per image, game-icons' author table); `gm packs sync --list` shows every mirror with its pin and licence; no live API adapter exists and no key is read.

## Context and evidence

B11 §4.6 lists live sources (Freesound, Openverse, ambientCG) that need API keys and network from the backend, and mirrors (KayKit, LPC, game-icons, Fontsource) that are git or npm sources with machine-readable licences; V1 approves no spending or new keys and the sandbox has no network (E05-16, D-SBX, R14), so tier 2 ships as pinned mirrors run by the operator and seen by build agents only through the index (R57). The existing fetchers (`fetch_itch_free.py`, `fetch_polypizza_bundle.py`, `fetch_drive_folder.py`) stay operator tools for `gm-pack-scout` (E05-16, T05 §3). B11 §4.7: "Any asset without a machine-readable license is dropped"; LPC: parse `CREDITS.csv` per image; game-icons: CC BY 3.0 with CC0 for listed authors; Fontsource: OFL per font.

Resolved already: tier 3 (agent-made) is `gm assets register` (OGM-062); live adapters are deferred; share-alike and GPL-only LPC items are excluded by default.

## Scope

- `packages/gm-cli/src/commands/packs/sync.ts`: a pinned mirror table `{ id, kind: 'git' | 'npm', source, pin, license: { default: SPDX | 'per-item', mapper }, id_prefix: 't2:<id>' }` with four entries: `kaykit` (git `KayKit-Game-Assets/*` packs listed by name, pinned commit, CC0-1.0 per `LICENSE.txt`), `lpc` (git `LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator`, pinned commit, per-item from `CREDITS.csv`: `filename, notes, authors, licenses, urls` → SPDX map `CC0-1.0`, `CC-BY-3.0`, `CC-BY-4.0`, `CC-BY-SA-3.0`, `OGA-BY-3.0`, `GPL-3.0-only`; keep CC0/CC-BY/OGA-BY, drop SA and GPL unless `--include-sa`), `game-icons` (git `game-icons/icons`, pinned commit, `CC-BY-3.0` with attribution = author folder name; CC0 authors from the repo's licence note mapped when listed), `fontsource:<font>` (npm `@fontsource/<font>` at a pinned version, licence from the package's `LICENSE`/`metadata` → `OFL-1.1` or `Apache-2.0`, dropped otherwise).
- `gm packs sync <mirror> [--pin <ref>] [--dest <download dir>] [--dry-run] [--json]`: `git clone --depth 1` + `git checkout <pin>` (or `npm pack @fontsource/<font>@<ver>`) into `~/Downloads/ogm-mirrors/<id>/<pin>/` (outside the repo), verifies the pin, builds `pack.json`-compatible metadata, then calls `gm packs import <dir> --id <id> --version <pin> --tier 2 --license <SPDX> [--license-map <csv-derived json>]` (OGM-064; `--tier` and `--license-map` are added to `import` here as two small flags) so cards get `t2:` ids and per-asset `rights` overrides where the map says so; `--list` prints the table; `--dry-run` fetches nothing and prints what would run.
- Attribution: `rights.attribution` per item from the credits (LPC authors joined; game-icons author; KayKit "KayKit"), so `CREDITS.md` (OGM-062) credits them.
- Emits `packs.sync` events (R88).

## Contract and invariants

Mirror table (producer; consumers: operators, `gm-pack-scout`):

```ts
// packages/gm-cli/src/packs/mirrors.ts
export type Mirror = { id: string; kind: 'git' | 'npm'; source: string; pin: string; title: string;
  license: { mode: 'single'; spdx: string; ref: string } | { mode: 'per-item'; mapper: 'lpc-credits-csv' | 'game-icons-authors' | 'fontsource-metadata' };
  subpaths?: string[] };                                 // for git repos, which folders to import
export const MIRRORS: Mirror[];
```

Licence map handed to `gm packs import --license-map` (consumer OGM-064): `Record<relativePath, { license: string; attribution: string | null; dropped?: string }>`; items marked `dropped` are not copied into `extracted/` and are listed in the import report.

Invariants: every imported item has a machine-readable SPDX licence or is dropped (B11 §4.7); ids are `t2:<mirror>/<path>@<pin>` with the pin as the version (a new pin is a new collection version, C3 §7); the sync never runs inside a game repo or a sandbox (`gm` refuses when `GM_JOB` is set); downloads land outside the repo and are untrusted (never executed); the import's effective rights for CC-BY items carry attribution, for CC0 `null`; `redistribution` is `free` for every kept licence.

## Failure, security, migration and accessibility cases

Clones and tarballs are untrusted data: no `npm install`, no scripts, no execution; `npm pack` runs with `--ignore-scripts`; the pin is verified before import; downloads live outside the repo under `~/Downloads/ogm-mirrors/`; a licence that cannot be mapped drops the item with the reason in the report; `GM_JOB` or a sandbox environment refuses the command; no keys are read (`~/.config/ogm` is not touched). No migration; no UI.
