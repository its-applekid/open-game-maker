## Outcome

`systemctl --user start ogm-voice-host` brings up a supervised `voice_converse` instance on `127.0.0.1:40400` that accepts a browser WebSocket carrying a token the OGM API minted, runs a whole conversation against `FakeProvider` with no key (frames in both directions, a draft confirmed and delivered to the API's instruct callback), stores no transcript, and switches to ElevenLabs Agents or OpenAI Realtime the day a key appears in its env file.

## Context and evidence

`voice_converse` on aiur `0f692a45b` is a working package: sessions, two live adapters, a wire codec, a standalone loopback WebSocket transport, an HMAC token issuer, drafts with Confirm, a no-transcript mode and a fake provider (E06-1, E06-3, E06-18). Its ports have 50–300 ms deadlines, so the host must answer from a cache the backend pushes, never by calling the backend inside a port (E06-9). `transcript: :none` disables provider cleanup, so the privacy policy pins `record_voice: false` (E06-4). No zero-spend provider exists; V1 wires everything against `FakeProvider` and turns on with a key (E06-7, D-VOICE-ZERO).

Contradictions already resolved: (1) B2 D3 "TypeScript relay first" is unnecessary (E06-1). (2) "Pin to a tag": the package has no tags (`version: "0.1.0"`); pin the commit `0f692a45b04bb4ce3e7d8256e134028894bd128b` as a git dependency with `sparse:`; the aiur agent is asked to tag (decisions.md upstream list 7). (3) GitHub CI cannot fetch the private aiur repo: the Elixir test suite runs on this host and its output is pasted into `## Local tests`; `ci / required` covers the TypeScript token route only. (4) `Config.roles`/`roles_dir` exist but are not read by any module at the pin (grep: only `config.ex`); role text goes through the briefing (OGM-086).

## Contract and invariants

Producer. T06 §4, quoted verbatim:

**Voice token (this track, consumed by T09; verified by the voice host).** `POST /api/voice/token` → `{ "token": "vct1.<payload>.<mac>", "expires_at": "2026-11-01T05:30:00Z", "url": "wss://<host>/voice" }`. Minting in TS: `payload = base64url(JSON{scope:"converse", sub:<creatorId>, exp:<unix>, nonce})`, `body = "vct1." + payload`, `token = body + "." + base64url(hmacSha256(secret, body))`, secret ≥32 bytes shared with the host's `Hmac.put_secret/2`.

**Session target (this track; the host's `BriefingSource.describe_target/1` reads it).**
```ts
type VoiceTarget =
  | { kind: "scope"; game_id: string; session_id: string; creator_id: string }
  | { kind: "build"; game_id: string; job_id: string; ticket: string; creator_id: string };
```
Sent as `{"v":1,"type":"start","target":VoiceTarget}`.

**Briefing cache push (this track → voice host; consumed from T01 budgets and T02 progress).** `POST http://127.0.0.1:<port>/internal/briefing` body `{ target_key, summary, current_task, next_steps[], waiting_on, questions[], extra: [{title:"Budget", text:"…"}], sections: [{id:"budget", text}, {id:"progress", text}] }`; the host serves ports from this cache within the 100/300 ms deadlines.

**Agent channel (voice host → OGM backend; this track).** `POST /internal/voice/instruct` `{ target, text, idempotency_key, kind: "instruct"|"ask" }` → `{ delivery_id }`; the backend routes `scope` targets to admission (`queue_change` semantics: `start: "now"|"at_reset"` parsed from a leading `[later]` marker in the confirmed draft) and `build` targets to aiur `POST /api/v1/:ticket/messages`.

Fixed here (append-only): the route is `/api/v1/voice/token`; `url` is `OGM_VOICE_WS_URL` (`wss://applekid.tailee0e71.ts.net:8443/ws/voice`, T11 §4); token TTL 300 s; `target_key` = `"scope:"+session_id` or `"build:"+job_id`; the push carries `observed_at` so stale data renders as stale, not idle; internal HTTP requires `X-OGM-Internal: <OGM_VOICE_INTERNAL_SECRET>` and binds loopback. Invariants: the token is verified by the package (scope `"converse"`), never logged; a target the creator may not edit never gets a token (`authorize(actor, "game.edit", { gameId })`); ports never do network I/O; the host runs with `transcript: :none` and writes nothing to disk; provider keys are read at use time from the unit env only.

## Failure, security, migration and accessibility cases

- No provider key: `OGM_VOICE_PROVIDER=fake` keeps the service healthy; the API's capability flag (`voice.conversation`, OGM-079) reads `/healthz`'s `provider` field to show the voice button or hide it.
- Token secret missing or < 32 bytes: the host refuses to boot and names the variable (`Hmac.put_secret` returns `:weak_secret`).
- Port deadline misses: the cache is ETS, in-process; a push that fails validation is rejected with 400 and the previous briefing stays.
- Secrets: only in `~/.config/ogm/env/ogm-voice-host.env` (0600); `ELEVENLABS_API_KEY`/`OPENAI_API_KEY` never in the repo or logs; the token secret is shared with the API's env file by Kevin (documented).
- Migration: none. Accessibility: not a UI ticket.
