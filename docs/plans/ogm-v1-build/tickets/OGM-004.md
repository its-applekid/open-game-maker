## Contract and invariants

Rights library (owner: this ticket; consumers OGM-010 policy, OGM-060/062 CLI, OGM-039 commit gate, OGM-093 skills):

```ts
// packages/contracts/src/rights.ts
export type Use = 'in-game' | 'placeholder' | 'derive-layout' | 'style-reference' | 'vision-input' | 'edit-audio' | 'derive-audio';
export type Audience = 'private' | 'public';
export type Redistribution = 'none' | 'in-build' | 'free';
export type Processing = 'local-only' | 'any';
export type RightsBasis = NonNullable<AssetCard['rights']>['basis'][number];   // from card.generated.ts
export type EffectiveRights = { uses: Set<Use>; audience: Audience; redistribution: Redistribution };
export class RightsError extends Error {}
export function effectiveRights(basis: RightsBasis[]): EffectiveRights;          // ceiling ∩ decisions; interpretations add uses only; throws RightsError on a forbidden add or no ceiling
export function rightsAgree(declared: NonNullable<AssetCard['rights']>, effective: EffectiveRights): boolean;
export function defaultProcessing(license: string | undefined, status: AssetCard['status']): Processing;  // 'local-only' for LicenseRef-*, NOASSERTION, undefined or quarantined; else 'any'
export function processingAllowed(card: AssetCard): { ok: true } | { ok: false; reason: string };         // the processing-rule check

// packages/contracts/src/card.ts
export type { AssetCard, MapLayoutSpec } from './card.generated.js';
export const ASSET_CARD_SCHEMAS = ['ogm.asset-card/1.0', 'ogm.asset-card/1.1'] as const;
export function validateCard(doc: unknown): { ok: true; card: AssetCard } | { ok: false; errors: string[] };
export function validateLayoutSpec(doc: unknown): { ok: true; spec: MapLayoutSpec } | { ok: false; errors: string[] };

// packages/contracts/src/layout.ts
export type LayoutMetrics = { loop_count: number; dead_end_count: number; room_count: number; connection_count: number; total_area_cells: number; secret_count: number; areas_ok: boolean; endpoints_ok: boolean };
export function layoutMetrics(spec: MapLayoutSpec): LayoutMetrics;

// packages/contracts/src/validate.ts
export type CheckResult = { file: string; check: string; ok: boolean; message?: string };
export function checkDocuments(docs: Array<{ file: string; doc: unknown }>): { ok: boolean; results: CheckResult[] };
// checks, in validate.mjs order: schema, rights=basis, no-model-rights, model-writes-allowlist, rights-resolvable, map-not-in-game,
// processing-rule (new), spec-source-allows-derive-layout, spec-linked-from-card, spec-loop-count, spec-dead-ends, spec-room-count,
// spec-areas, spec-secrets, spec-endpoints-exist
```

CLI (consumed by the Python workers): `node packages/contracts/bin/validate-cards.mjs [--no-fixtures] [file...]` validates the 16 fixture cards plus the files, prints `ok  <check>  <basename>` or `FAIL <check>  <basename>  <message>` per check and `all checks passed` or `<n> failure(s)`, exit 1 on any failure (byte-compatible with today's lines; Python greps `^FAIL`).

Schema change (the only edit to the moved files): `$defs.rights.properties.processing = { enum: ['local-only', 'any'] }` (optional) and `properties.schema` becomes `{ enum: ['ogm.asset-card/1.0', 'ogm.asset-card/1.1'] }`; `vocab` stays `2026-10-27`; `$id` unchanged.

Emit convention (consumed by OGM-010, OGM-020, OGM-050 …): `src/<family>.ts` exports `schemas`; `pnpm --filter @ogm/contracts check` runs `generate --check`, `emit --check` and `check-fixtures`; emitted files are committed.

## Failure, security, migration and accessibility cases

- A card whose declared `rights` disagree with `effectiveRights(basis)` is refused (`rights=basis`), as today; a model-written rights field is refused (`no-model-rights`).
- `processing: any` on a `LicenseRef-*`, `NOASSERTION` or quarantined card is refused; absence is allowed (old cards) and read as `defaultProcessing`.
- The shim must fail loudly when `dist/` is absent (`run: pnpm --filter @ogm/contracts build`, exit 2), never silently pass.
- Fixture cards contain no download links, keys or serials (the schema's `ref` rule); the review checks the moved files are byte-identical apart from the two schema edits and the example `processing` additions.
- No secrets, migrations or UI.
