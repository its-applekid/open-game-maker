## Outcome

`@ogm/voice-client` gives the web app three things that work on a phone with no server and no key: a two-way voice client that speaks the `voice_converse` v1 wire protocol (AudioWorklet capture at 16 kHz PCM16, PCM playback, captions, draft cards with Confirm/Discard) and is proven against a replayed frame fixture; push-to-talk dictation through the browser's Web Speech API with partial and final captions and review-before-send; and read-aloud through `speechSynthesis` with sentence highlighting.

## Context and evidence

The wire contract is versioned JSON (`v: 1`, 16 frame types) with a JSON Schema, generated TypeScript types and a fixture in `@aiur/contracts`; the browser client is a single ES module using the deprecated `createScriptProcessor` and no captions (E06-2). aiur's dictation lives in the aiur app, not the package; zero-spend dictation is the Web Speech API (E06-11, adults only in V1). Captions and read-aloud ship at zero cost; `speechSynthesis` boundary events are unreliable on iPad so highlighting is per sentence (E06-12). The prototype's `VoiceSession` is theatre; only its two-column layout survives as a design reference (E06-19).

Contradictions already resolved: (1) The decision log's "a TS voice client (npm)" does not exist; `@aiur/contracts` is unpublished (`0.1.0`), ships no `dist/`, and lives only in the local aiur checkout, which GitHub CI cannot reach. The schema and generated types are therefore vendored into this package with a sync script and a provenance header, pinned to `0f692a45b` (architecture's "re-export of @aiur/contracts" reads as "vendored copy"). (2) A6 §10's "no Web Speech API" was a children's-data rule, moved to V3; V1 dictation uses it with a settings notice (D-VOICE-ZERO). (3) Live alignment and usage frames do not exist upstream (E06-6): live captions are sentence-level from `agent_text` frames, no word highlighting; session minutes are counted in the client from `start`/`ended`.

## Scope

- `packages/voice-client/src/wire.ts`: vendored `VoiceConverseFrame` types (copied from `packages/aiur-contracts/src/voice-converse.generated.ts`) and `schemas/voice-converse.v1.schema.json`; `encode()`/`decode()` with `v: 1` check; unknown fields survive.
- `packages/voice-client/src/client.ts`: `VoiceClient` port of `priv/static/voice_converse_client.js`: `connect({ url, token, target })` (token as `?token=`), `startFromGesture()` (getUserMedia only inside a user gesture), AudioWorklet capture → 16 kHz PCM16 → `audio{data_b64}` frames, PCM playback queue for `agent_audio` (`pcm_16000|pcm_24000|pcm_44100`), `interrupted` stops playback, `confirmDraft(id, editedText?)`, `discardDraft(id)`, `end()`, typed events (`state`, `transcript`, `agent_text`, `draft`, `delivery`, `context_gap`, `error`, `ended`), minutes counter.
- `packages/voice-client/src/captions.ts`: a reducer from `transcript`/`agent_text` frames to a two-column caption model (you / builder) with sentence splitting; framework-free (the React panel in OGM-076 renders it).
- `packages/voice-client/src/dictation.ts`: `Dictation` wrapping `SpeechRecognition`/`webkitSpeechRecognition`: `pressStart()`/`pressEnd()` (push-to-talk), `interimResults`, emits the same `transcript{kind: partial|final}` shape, final text becomes a draft the UI confirms (review-before-send); `isSupported()`.
- `packages/voice-client/src/speak.ts`: `speak(text, { lang, rate, onSentence(i), onEnd })` over `speechSynthesis` with one utterance per sentence; `cancel()`; `isSupported()`.
- Tests: Vitest with the vendored fixture; a Playwright run in headless Chromium with fake media devices against a local fake WebSocket server replaying frames.

## Contract and invariants

Consumer of the upstream wire contract (vendored, pinned to `0f692a45b`); do not redefine frames. Client→server frames: `start{target}`, `audio{data_b64}`, `text{text}`, `confirm_draft{draft_id, edited_text?}`, `discard_draft{draft_id}`, `end`. Server→client: `state{state}`, `transcript{kind, text}`, `agent_text{turn_id, text, final}`, `agent_audio{turn_id, format, data_b64}`, `interrupted{turn_id}`, `draft{draft_id, kind, target, text, status}`, `delivery{draft_id, message_id?, status}`, `context_gap{source, message}`, `error{code, message}`, `ended{reason}`. Package API this ticket produces:

```ts
export class VoiceClient { constructor(o: { url: string; token: string; target: Record<string, unknown> });
  startFromGesture(): Promise<void>; end(): void; sendText(t: string): void; confirmDraft(id: string, edited?: string): void; discardDraft(id: string): void;
  on<K extends ServerFrameType>(type: K, fn: (f: FrameOf<K>) => void): () => void; minutes(): number }
export function captionsReducer(state: Captions, frame: ServerFrame): Captions;   // { you: Line[]; builder: Line[] }
export class Dictation { static isSupported(): boolean; pressStart(): void; pressEnd(): void; on(ev: "transcript"|"error", fn): () => void }
export function speak(text: string, o?: { lang?: string; rate?: number; onSentence?: (i: number, s: string) => void; onEnd?: () => void }): { cancel(): void };
```
Invariants: `getUserMedia` is requested only inside `startFromGesture()` (called from a pointer event); frames are ≤ 400,000 bytes (transport cap in `transport/websock.ex`), audio chunks ~100 ms; the client never logs the token or audio; `text` frames are sent only when the host advertises text input (the standalone transport refuses them today, E06-7); dictation sends nothing until the UI confirms the final text; a `4401` close surfaces as `error{code:"unauthorized"}`.

## Acceptance and verification

### Agent gate
- `pnpm --filter @ogm/voice-client test`: every frame in the vendored fixture decodes and re-encodes equal (fails if `wire.ts` drops a type); `captionsReducer` turns partial→final transcripts into one line and splits `agent_text` into sentences; `dictation.ts` with a stubbed `SpeechRecognition` emits `partial` then `final` and does not emit until `pressEnd()`; `speak()` with a stubbed `speechSynthesis` calls `onSentence` once per sentence in order; the sync script is idempotent (`--check` exits 0 on a clean tree, 1 after a hand edit of `wire.ts`).
- `pnpm --filter @ogm/voice-client e2e` (Playwright, headless Chromium with `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`, GPU flags `--use-angle=gl-egl --enable-gpu --ignore-gpu-blocklist`, `GM_VERIFY_SOFTWARE_GL=1` fallback): the client connects to the fake server with `?token=`, sends `start`, streams ≥ 5 `audio` frames of PCM16 at 16 kHz within 2 s, plays an `agent_audio` frame (AudioContext time advances), stops on `interrupted`, renders a draft and sends `confirm_draft` on Confirm; a server that closes with `4401` yields `error{code:"unauthorized"}`.

## Failure, security, migration and accessibility cases

- No microphone permission: `startFromGesture()` rejects with `mic_denied`; the UI falls back to dictation or typing.
- `SpeechRecognition` unsupported (Firefox): `Dictation.isSupported()` false; the UI hides the button.
- Socket drop mid-session: capture stops, `ended{reason:"transport_lost"}`-equivalent local event, minutes recorded.
- Privacy: the Web Speech API sends audio to the browser vendor; a one-line settings notice is OGM-071/079's; this package exposes `Dictation.vendorNote` text for it.
- No secrets in the package; the token is held in memory only and appended to the URL once.
- No migration. Accessibility: captions are plain text in two labelled regions; push-to-talk is a single 64 px control (the UI's), and `speak()` respects `prefers-reduced-motion` only in the renderer (none here).
