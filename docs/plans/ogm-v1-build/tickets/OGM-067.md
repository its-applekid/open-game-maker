## Outcome

`gm packs blocklist` writes one sorted `sha256  bytes  path` file covering every byte of every `redistribution: none` collection (originals, extracted files, previews, generated variants and the ProFantasy hash manifest) that the commit service (OGM-039) reads from `OGM_BLOCKLIST_FILE`; `gm packs index` rebuilds the card index on demand and, with `--import-previews`, copies previews and private manifests into the filesystem blob store without moving an original; `gm maps search "small crypt 3-5 rooms one loop secret door"` lists layout specs whose source card grants `derive-layout`.

## Context and evidence

Publish enforcement today is name-based (`rm -f art/packs/synty-*`) and the only hash blocklist covers ProFantasy's CC3+ tree, written by `scripts/maps/hash_manifest.py` to `assets-local/private/hash-manifests/profantasy-cc3-v1.txt` (E05-14). C3 §5 requires the commit check to reject any file whose sha256 belongs to a `redistribution: none` asset including its previews and variants; T03 §4 puts that check in the commit service's `BoundaryVerdict` (`code: 'denylist'`) with the feed owned by T05 (E03-16). No S3 store exists; the blob store is a filesystem `BlobStore` under `OGM_BLOB_ROOT` (E05-4, E11-8, D-BUCKET, OGM-005) and `assets-local/` has `previews/`, `private/` and `derived/` prefixes undocumented in the reference (E05-18) that must map to blob keys without moving Kevin's files. Map search goes through layout specs and requires `derive-layout` (C3 §10, §12); the ProFantasy collection today grants `vision-input` only (`catalog.json` `rights_uses`), so results are empty until an admin decision adds `derive-layout` (OGM-064 `--confirm --decision`).

Resolved already: no layout-spec extraction in V1 (it needs a vision model; the CAD sidecars are a future code-only source); the feed is a file, not an API; originals never move.

## Scope

- `gm packs blocklist [--out <file>] [--json]`: for every collection whose effective `redistribution === 'none'` (index), hash every file under `packs/<id>/<ver>/{originals,extracted}` or `inspiration/<id>/**`, every preview key the collection's cards reference (`previews.thumb|sheet|waveform|clip`), every `derived/<id>/**` variant, and append every line of `collection_info.hash_manifest` files; write sorted unique `sha256  bytes  path` lines (paths relative to the library root, never absolute) to `--out` (default `assets-local/private/blocklist/redistribution-none.txt`) and print the count; incremental by file mtime+size cache under `assets-local/private/blocklist/cache.json`.
- `gm packs index [--families] [--import-previews] [--json]`: runs `buildIndex` (OGM-060) explicitly and prints counts and errors; `--families` runs OGM-066's `computeCoverage` and rewrites `style-families.json` coverage; `--import-previews` puts every file under `assets-local/previews/**`, `assets-local/private/previews/**` and `assets-local/private/hash-manifests/**` into the blob store (`BlobStore.put` from OGM-005, idempotent by hash), records `previews.blob = { thumb: 'sha256:…', … }` on the cards' index entries (index only, cards untouched) so the API can sign URLs; private prefixes are recorded with `visibility: 'private'`.
- `gm maps search "<words>" [--rooms 3-5] [--loops N] [--secret] [--size small|medium|large] [--type dungeon|cave|…] [--json]`: over `assets-local/inspiration/*/layouts/**/*.layout.json` (layout specs, schema `ogm.map-layout-spec`) plus, with `--cards`, map cards' `map.map_type`/`describe` as a weaker fallback; filters on `tags.computed` (room_count, loop_count, secret_count, size_class) and `tags.judged` (map_type, themes, flow); requires the source card's resolved rights to include `derive-layout`, else the spec is excluded and counted in a `hidden (no derive-layout)` line; output `spec-id  type  rooms  loops  secrets  size  flow  thumb-key`.
- `assets.blocklist|index|maps.search` events (R88).

## Contract and invariants

Hash blocklist (producer T05; consumer OGM-039 commit service), quoted from T05 §4:

> Text file, sorted, `sha256  bytes  path`, union of all `redistribution: none` sources, variants, previews and hash manifests.

Line grammar: `^[0-9a-f]{64}  [0-9]+  [^\n]+$`, two spaces between fields, LF line endings, sorted bytewise, unique by `(sha256, path)`; `path` is relative to `assets-local/` (or `manifest/<name>/…` for lines copied from a hash manifest). The consumer matches on the sha256 column only. Env name for the consumer: `OGM_BLOCKLIST_FILE` (declared in `packages/config`, OGM-003) pointing at the default output.

Blob keys (consumer OGM-005's `BlobStore`): previews are stored content-addressed (`blobs/sha256/<hex>`); the index entry gains `previews.blob: Partial<Record<'thumb'|'sheet'|'waveform'|'clip', `sha256:${string}`>>` and `visibility: 'private' | 'library'`; cards on disk are never edited by `--import-previews`.

Invariants: a `redistribution: none` asset's previews are always in the feed (C3 §7); the feed never contains absolute paths, keys or serials; the ProFantasy manifest's 2,000+ symbol bitmaps that have no cards are still listed (via the hash manifest); `gm maps search` never returns a spec whose source lacks `derive-layout`; originals in `assets-local/` are read, never written or moved.

## Failure, security, migration and accessibility cases

The feed lists hashes and relative paths of private files; it lives under `assets-local/private/` (gitignored) and is read by the commit service through an env path, never committed or served; a hash collision between a `none` file and a legitimate public file is impossible in practice and would surface as a `denylist` reason with the path for review; `--import-previews` is idempotent and never deletes; a missing `OGM_BLOB_ROOT` exits 2 naming it; `gm maps search` prints spec ids and thumb keys, never image bytes or map text (C3 §12 `notes` are our words). No migration; no UI.
