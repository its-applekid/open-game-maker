## Outcome

From any directory, `gm assets search dungeon wall --kind model/kit` prints one line per hit from the 414 installed packs (rights-filtered to `in-game` by default), `gm assets facets`, `info`, `sheet` and `list` work the same way, `--json` returns resolved cards, and every other lane can add a command by dropping one file into `packages/gm-cli/src/commands/<namespace>/`.

## Context and evidence

No `gm` binary exists anywhere in the repo; every skill that names `gm assets …` is aspirational (E05-20, E10-16). The library is 414 packs from seven vendors with 278 tagged collection cards, 128 draft Sidetrax cards and 8 uncarded packs (E05-1, E05-3); per-asset cards exist only for audio (2,814) and maps (2,092). The rights engine exists as `docs/research/v0.5/schemas/tools/validate.mjs` and is ported to TypeScript by OGM-004 (E05-9, E12-7). B11 §4.7 fixes the CLI's token-saving conventions (one line per hit, `--limit 10`, `--json`, errors as one cause line plus a suggested command). This ticket is the spine of the assets lane and a hot write surface shared with the skills, chat-voice and engine lanes (T12 "hot write surfaces": command-per-file with a directory scan, no central registry).

Resolved already: the index is built from cards, not from `catalog.json` (C3 §9; the catalog stays a pack list for the Python scripts); search defaults include `measured` and `draft` for `model`/`sprite` kinds until a tagging pass exists (E05-3), and `tagged|reviewed` for audio and maps; the rights engine and schemas are imported from `@ogm/contracts` (OGM-004), never redefined here.

## Scope

- `packages/gm-cli` (`@ogm/gm-cli`, bin `gm`): a directory-scanned command registry (`src/commands/<ns>/<cmd>.ts` each exporting `command: GmCommand`), shared flags `--json`, `--limit N` (default 10), `--fields a,b`, exit codes 0 ok / 1 check failed / 2 refusal or usage error with one-line cause and a suggested command, `gm help <cmd>` ≤ 15 lines, no colour or progress when stdout is not a TTY.
- Library root resolution: `OGM_ASSETS_ROOT`, else walk up from cwd to a directory containing `assets-local/catalog.json`; otherwise exit 2 naming the variable.
- Activity events: `src/events.ts` appends `{event, job_id, ts, payload}` JSONL to `$GM_EVENTS_FILE` when set (E05-19, R88); event names `assets.search|facets|info|sheet|list` here, extended by siblings.
- `packages/asset-cards` (`@ogm/asset-cards`): `buildIndex(root)` reads every `packs/*/collection.card.json`, `packs/*/cards/**/*.card.json`, `inspiration/*/collection.card.json` and `inspiration/*/cards/**/*.card.json`, validates with `@ogm/contracts`, resolves inheritance (C3 §8: license, rights, style_family, pov_fit, settings, environments; `by: collection` provenance) and writes `assets-local/index/cards.index.json`; `search(index, query)`, `facets(index, filters)`, `info(index, ids)`; rights-aware defaults (C3 §10).
- `gm assets search <words> [--kind k[/sub]] [--family f] [--pov p] [--use u] [--rig-id r] [--same-rig-as id] [--include-draft] [--tier 1|2|3] [--collection id]`, `gm assets facets [filters] [--proposed]`, `gm assets info <id...>`, `gm assets sheet <id...> [--out sheet.png]` (grid of existing preview images via `sharp`, up to 24, labelled), `gm assets list` (read-only over `assets.lock.json` when present).
- Index staleness: a command rebuilds the index when any card is newer than the index file or the index is missing.

## Contract and invariants

`gm` CLI conventions (producer; every lane copies them):

```ts
// packages/gm-cli/src/command.ts
export type GmCommand = {
  name: string;                 // "assets search"
  summary: string;              // one line, shown by `gm help`
  flags: Record<string, { type: 'string' | 'number' | 'boolean'; default?: unknown; help: string }>;
  run(ctx: GmContext, args: string[], flags: Record<string, unknown>): Promise<number>;  // exit code
};
export type GmContext = { cwd: string; assetsRoot: string | null; json: boolean; limit: number; out: (line: string) => void; emit(event: string, payload: unknown): void };
// exit codes: 0 ok, 1 a check failed (gm check, gm test), 2 refused or bad usage: one line "<cause>. Try: gm <command>"
```

Asset index (producer; consumers OGM-062/063/066/067, OGM-074 through the API):

```ts
// packages/asset-cards/src/index.ts
export type ResolvedCard = AssetCard /* from @ogm/contracts */ & { resolved: { license: string; rights: Rights; style_family?: string; pov_fit?: string[] } };
export type CardIndex = { version: 1; built: string; vocab: string; cards: ResolvedCard[]; collections: Record<string, ResolvedCard> };
export function buildIndex(root: string): Promise<CardIndex>;           // validates every card; invalid cards are listed and skipped
export function search(index: CardIndex, q: SearchQuery): ResolvedCard[]; // rights.uses ∋ q.use ?? 'in-game'; status filter per kind
export function facets(index: CardIndex, q: SearchQuery): Record<string, Record<string, number>>;
```

Invariants: the index never widens rights (resolution is the C3 §5 intersection, computed by `@ogm/contracts` `effectiveRights`); `inspiration` cards never pass an `in-game` search; `quarantined` cards are invisible to search; output rows are `id  kind/subkind  status  family  title` in that order.

## Failure, security, migration and accessibility cases

Invalid cards are reported and skipped, never crash the index; `assets-local/` stays gitignored and no card content, path under `private/` or preview bytes are printed by `--json` beyond bucket keys; the CLI reads no secrets and needs none (`OGM_ASSETS_ROOT`, `GM_EVENTS_FILE`, `GM_JOB` only); `sheet` writes only to `--out` or `./sheet.png`. No migration; no UI.
