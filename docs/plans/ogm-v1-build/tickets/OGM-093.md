## Outcome

In a scaffolded game, `gm check` exits 1 naming the file and line when simulation code calls `Math.random` or `Date.now`, when `tsc` fails, or when the `GameModule` has no test hooks; `gm test` boots the game headless, advances 3,600 ticks, round-trips `renderGameToText()` through `restore`, takes a HUD still and fails if any step throws or the still is blank (AE6); the `gm-verify` skill tells a worker how to look, what to check, which budgets block and what to list as unchecked, in under 80 lines and without a single prototype path.

## Contract and invariants

Consumer of OGM-090's `VerifyReport` (copy from `packages/gm-verify/src/report.ts`; do not redefine) and OGM-020/022's `GmTestHooks` (copy from `packages/contracts/game.ts`). This ticket defines the gate result shape used by `gm check`, `gm test`, OGM-096's repair acceptance and OGM-100's checklist:

```ts
export interface GateResult { gate: 'L0' | 'L1'; ok: boolean; durationMs: number;
  checks: { id: 'typecheck' | 'no-wall-clock-in-sim' | 'hook-present' | 'boot' | 'ticks' | 'round-trip' | 'hud-still' | 'promises';
            ok: boolean; detail?: string; file?: string; line?: number }[];
  report?: string /* path to report.json when a browser ran */ }
```

Invariants: L0 never launches a browser; L1 runs under OGM-090's semaphore and queue rules; a check that cannot run (no `tsc`, no browser) is `ok: false` with `detail: 'unavailable: …'`, never skipped silently; exit code 1 on any `ok: false`; the skill never names a file outside the game repo.

## Failure, security, migration and accessibility cases

- `restore` not reachable from `window.__gm` in test builds: `round-trip` is `ok: false, detail: 'unavailable: __gm.restore'` and the PR names OGM-022; the gate still runs the other checks.
- Flaky boot on a loaded host: one retry for `boot` only, recorded in `detail`.
- Loopback only; no network; no secrets; L1 runs `nice 10` through OGM-090.
- Accessibility: the HUD still check also records text contrast as `unchecked` (advisory; no blocking in V1).
- No migrations, no UI.
