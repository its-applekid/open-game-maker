## Outcome

On a phone, `ogm2000.netlify.app/` paints the castle-town poster first, the live town fades in over it with its sounds playing on the app's unlocked audio with no cut, a tap on the town reaches its Easter egg, a controller or keyboard moves focus through the app's menus, a push subscription can be registered after the user allows it, and a bug button on every app screen files a report.

## Context and evidence

The live title is the castle town in an iframe with a poster-to-live reveal and an sfx/tap relay (E09-3), and Kevin's direction keeps it (memories `title-city-scenes`, `kevin-seamless-transitions`). The town is plain ES modules bundled by `prototypes/title-city/tools/bundle.mjs` and must be served unbundled by Vite from `public/town/` (E09-3). The iOS audio rules are encoded in `sound.js` (E09-7). The host is the only gamepad reader and Norigin Spatial Navigation (491 stars) is Kevin's approved exception to the 1k rule (E09-14). Notifications need the PWA shell OGM-070 ships and a VAPID public key from the backend (E09-16, OGM-016). The bug button posts to `POST /api/v1/reports` (T01 §4, OGM-015). Both backend tickets are advisory ordering only: this ticket must degrade when their routes 404. The parent↔town protocol uses `'*'` targets today (E12-4); here the town is same-origin, so messages are checked by `e.source` and sent to `location.origin`.

## Scope

- `src/routes/title/`: the title screen (logo, Start, sound toggle) over `TitleTown`, a React component porting `prototypes/studio-v0/title-town.js`: poster `<picture>` painted first, iframe `town/index.html?cam=menu&scene=all&embed` created only while the title is shown, removed on leave, `'town-ready'` fades the poster out after the town's first frame, `{sfx}`/`{loop}` relayed to `lib/sound`, `{tap:[x,y]}` posted for taps that miss buttons, `'pause'`/`'resume'` on visibility.
- `public/town/`: gitignored build output produced by `apps/web/tools/town.sh` from the title-city build (`build.sh`, `bake.mjs`, `poster.mjs`, `bundle.mjs`), the castle-town subset the studio's `build.sh` lines 85–103 copy; `public/art/music/` Kenney tracks only in public deploys.
- `src/lib/sound/`: TypeScript port of `sound.js`: one `AudioContext`, music/sfx buses, loop points, duck, `unlock()` on `pointerup`/`touchend`/`keydown`/`click` (capture), `navigator.audioSession.type = 'playback'`, suspend in hidden tabs, `ext`/`extLoop`/`extSilence`, mute and volume in `localStorage`.
- `src/lib/input/`: one `requestAnimationFrame` gamepad poller with edge detection that dispatches synthetic `keydown` (`ArrowUp/Down/Left/Right`, `Enter`, `Escape`) on the focused element while no game is in play mode, `onFrame(cb)` for OGM-075 to forward raw frames, and focus zones with `@noriginmedia/norigin-spatial-navigation` (`FocusZone`, `useFocusable`).
- `src/lib/notify/`: `requestPushPermission()` on an explicit tap, `subscribePush()` → `POST /api/v1/push/subscriptions { endpoint, keys }`, `useNotificationFeed()` over `GET /api/v1/notifications/stream` (SSE) rendering toasts.
- `src/features/bug-report/`: a 44 px FAB in the app chrome posting `POST /api/v1/reports` with the context the current screen registered; when the route is unreachable the report is kept in `localStorage` and retried on the next load.

## Contract and invariants

**Title town embed (T09 §4, verbatim; this ticket hosts it).** parent→town `{tap:[x,y]}`, `'pause'`, `'resume'`; town→parent `'town-ready'`, `{sfx:[name,vol,rate]}`, `{loop:[name,gain]}` (`city.js:7-8`).
Invariants: the poster is in the first paint; the poster fades only after `'town-ready'`; no dim cross-fade; the iframe is `aria-hidden`, `tabIndex=-1`, `pointer-events:none`; sounds come from the host's context, never the iframe's; the iframe `src` is set after the title music has decoded or 2.5 s, whichever is first; leaving the title removes the iframe and silences loops.

**Sound (this ticket).**
```ts
export const MUSIC: Record<'title'|'menu', { file: string; loop: [number, number]; fallback: string }>;
export function set(track: 'title'|'menu'|'off', fade?: number): void;   export function cue(name: string, vol?: number): void;
export function ext(url: string, vol: number, rate: number): void;      export function extLoop(url: string, gain: number): void;  export function extSilence(): void;
export function unlock(): void;  export const status: () => 'off'|'on'|'tap';  export const onChange: (f: (s: ReturnType<typeof status>) => void) => void;
export function setMuted(m: boolean): void;  export function setVolume(v: number): void;  export const titleReady: Promise<AudioBuffer | null>;
```
**Input (this ticket).** `startGamepadPoller(): () => void`; `onFrame(cb: (f: GamepadSnapshot) => void): () => void` where `GamepadSnapshot = { index: number; axes: number[]; buttons: { pressed: boolean; value: number }[]; t: number }`; `setPlayMode(on: boolean)` stops synthetic keys while on. Invariant: exactly one `getGamepads()` caller in the app.
**Bug report (this ticket consumes T01 §4, OGM-015).** `POST /api/v1/reports { "gameId", "releaseId", "buildHash", "text"?, "error"?: {"type","message","frames":[…]}, "bundleKey": "<private bucket key from T05 signed upload>" } → 201 { "reportId", "signature", "route": "game_repair"|"platform"|"editor_hint"|"stored", "jobId"? }`. Screens set context with `setBugContext({ gameId?, releaseId?, buildHash? })` from the `bugReport` store slice.
**Push (consumes OGM-016).** `POST /api/v1/push/subscriptions { endpoint, keys }`; `GET /api/v1/notifications/stream` (SSE `event: build.done | job.started | intake.report`). The VAPID public key endpoint is OGM-016's to name; this ticket reads it through one function `fetchVapidPublicKey()`.

## Failure, security, migration and accessibility cases

- A town that never posts `'town-ready'` leaves the poster up (acceptable); a 20 s watchdog logs once and keeps the poster.
- `postMessage` targets are `location.origin`, never `'*'`; messages are accepted only from `iframe.contentWindow`.
- The bug button never sends secrets or prompt text; the local retry queue holds only what the user typed and the error summary.
- Push permission is requested only from a tap, never on load; denial is remembered in the store so the prompt is not repeated.
- Targets: Start 64 px; bug FAB and sound toggle 44 px with `aria-label`s; the town iframe is hidden from assistive tech; reduced motion disables the poster fade (poster hides at once).
- No migration.
