## Outcome

`POST /api/v1/jobs/:id/cancel` returns 200 only after aiur confirms `process.status: "exited"` and the job reads "Stopped"; `pause`, `resume`, `message` and `decide` reach the right daemon; every 60 s (and on each `usage.changed` event) a running job's `usageMicroUsd` equals aiur's `api_equivalent.amount.USD` with one `usage_samples` row per `run_id`; when a job reaches `done|failed|cancelled|out_of_budget` its reservation and slot are released once.

## Context and evidence

Cancel is an API call that confirms the process exited (E02-7); usage is a versioned read with exact-decimal money and per-run sessions (E02-5); the cap trips inside aiur (E02-4), so OGM reconciles rather than enforces, except as a fallback when `coverage.status` is not `complete` (T02 R3). Allowances are api-equivalent micro-dollars (E01-13, D-BUDGET-UNIT). Checkpoint answers go to aiur's decisions API on the supervisor token (E06-15). Resolved: B8's "apply `agent:cancelled` and wait" is replaced by the cancel route; "at the hard cap apply cancelled" is replaced by the cap set at filing (OGM-031); thresholds and offers remain OGM-013's.

## Scope

- `services/api/src/jobs/controls.ts`: a Hono sub-router with `POST /api/v1/jobs/:id/{cancel,pause,resume,message,decide}`; each: `authorize(actor, 'job.cancel'|'job.edit', job)` (OGM-012's policy; `message`/`decide`/`pause`/`resume` use `job.edit`), resolve the daemon client via `fleet.daemonFor(job.aiurRepo)` (OGM-034), call `@ogm/aiur-client`, update the job row, respond. Cancel before dispatch (`agent_not_running` and job `filed`): `issues.setStateLabel(repo, n, 'cancelled')` (OGM-031) and job `cancelled`. Cancel 409 `still_running|kill_failed`: retry up to 3× over 10 s, then 503 with the status and an admin alert. `message` passes the chat message id as `messageId` (OGM-080 mirrors creator text through this route). `decide` posts `{option, expected_version, idempotency_key: checkpointId+version}` and marks the `checkpoints` row (OGM-032) `answered`.
- `services/api/src/budget/aiur-usage.ts`: `reconcileJob(jobId)` reads `/usage`, converts `totals.api_equivalent.amount.USD` to micro-dollars (exact decimal parsing, no floats), upserts `usage_samples(job_id, repo, issue, run_id, provider_reported_micro, api_equivalent_micro, coverage_status, observed_at)` from `sessions[]`, sets `jobs.usageMicroUsd`, `usageCoverage`, `aiurRunId` (latest session), then calls OGM-013's `budget.applyUsage(job, usageMicroUsd, coverageStatus)` which owns the 1× pause and hard-cap decision; when `coverage.status !== 'complete'`, passes `pessimisticMicroUsd = max(usage, reservation)`. Scheduler: every 60 s for jobs in `filed|running|paused_budget` stages, immediately on OGM-032's `usage.changed` event, and once more on terminal transition.
- Terminal release: on `job.stage.changed` to `done|failed|cancelled|out_of_budget` call `budget.releaseReservation(jobId)` and `slots.release(jobId)` (OGM-013) exactly once (`releasedAt` column guard).

## Contract and invariants

Consumer. Copy `AiurClient` from OGM-030 `packages/aiur-client/src/client.ts`; copy the job row and `POST /api/v1/jobs` shapes from OGM-013 (`packages/contracts/jobs.ts`); copy `JobStage` from OGM-032 (`packages/contracts/src/job-stage.ts`); do not redefine. Money: `usd` decimal string → micro-dollars with `BigInt` arithmetic on the string (`"12.345678"` → `12345678n`); reject more than 6 fraction digits. Invariants: a cancel is "confirmed" only on `process.status === "exited"` or `agent_not_running` with a successful label swap; reservation release happens once per job; `usage_samples` is keyed `(job_id, run_id)` and updated in place; the reconciler never lowers `usageMicroUsd`; `decide` uses an idempotency key derived from `(decisionId, version)` so a double tap is harmless.

## Failure, security, migration and accessibility cases

Daemon stopped between filing and cancel: `daemonFor` returns null → cancel falls back to the label swap (aiur will not dispatch a `cancelled` ticket) and the job is `cancelled`. `usage_unavailable` (503) is retried next tick, never treated as zero. Supervisor token absent → `decide` returns 503 `checkpoints_unavailable` with an admin alert; nothing else is affected. Routes are session-authenticated through the Netlify proxy (OGM-011); no aiur token or usage internals reach the client beyond micro-dollars and stage. Migration timestamped. UI is OGM-076's; buttons it renders for these routes are 64 px primary targets.
