## Contract and invariants

Consumer of OGM-091's skill-pack layout (`.claude/skills/vendor/{phaser,threejs,gamedev}/`, `skills.lock.vendored`): copy from OGM-091, do not redefine. This ticket defines only:

```ts
// tools/skills/check-api-names.ts
export interface ApiCheckResult { skill: string; library: 'three' | 'phaser'; classes: string[]; methods: string[];
  missing: { name: string; kind: 'class' | 'method'; file: string; line: number }[] }
export function checkSkillDir(dir: string, lib: 'three' | 'phaser', libSrcRoot: string, allow: string[]): ApiCheckResult[];
```

Invariants: every vendored file has the three front-matter keys; no file under `skills/vendor/` contains `http://` or `https://` in a code block except inside a comment marked `// reference:`; no `scripts/`, hooks or executables are vendored (a test asserts no file is executable and no `.sh`/`.py`/`.js` exists under `skills/vendor/`); the allowlist for benign misses (Web Canvas/Audio APIs, placeholder user functions, v3 names inside `v3-to-v4-migration`) is a checked-in JSON, not a code change.
