## Outcome

`services/games-host` listens on `127.0.0.1:$OGM_GAMES_PORT` and serves `GET /g/<gameId>/<buildId>/<path>` from `$OGM_GAMES_ROOT/<gameId>/<buildId>/` only when that build directory carries a `.complete` marker, with a locked CSP, `Cross-Origin-Opener-Policy`, `Permissions-Policy`, immutable caching and never a cookie; `GET /healthz` answers the T11 health JSON; a Playwright test proves a page on another loopback origin can frame a build with the T04 sandbox attributes while a non-allowed parent cannot, the game sees no cookies, and a fetch to a third origin is blocked by CSP.

## Context and evidence

Games run in a separate-origin sandboxed iframe (R40); with no domain to buy, V1 serves every game from one shared origin `https://applekid.tailee0e71.ts.net:10000/g/<gameId>/<buildId>/` that is cross-site to the app (E11-7, D-GAMES-ORIGIN); saves and settings go through the bridge only, and the limitation (shared storage and mic grant across a family's games) is recorded. The host attributes T04 requires are `sandbox="allow-scripts allow-same-origin allow-pointer-lock"` and `allow="autoplay; fullscreen; gamepad; microphone"` (T04 §4, B4 D3-B). Every tested build artifact is kept (E08-20), so build directories are immutable and cacheable forever. Resolved: T08 §3 wrote `/g/{gameId}/b/{buildId}/`; decisions.md wins: no `/b/` segment. The service binds loopback and Tailscale fronts it (E11-11, OGM-006).

## Scope

- `services/games-host` (`@ogm/games-host`): Hono on `@hono/node-server`, routes `/healthz` and `/g/:gameId/:buildId/*`, id validation, path containment, `.complete` gating, `index.html` default, MIME by extension (`.js`, `.mjs`, `.wasm`, `.json`, `.glb`, `.ktx2`, `.webp`, `.png`, `.mp3`, `.html`, `.css`, `.map`).
- The response header set (contract below) and the "no cookies in, no cookies out" rule.
- `src/layout.ts`: `buildDir(root, gameId, buildId)`, `isComplete(dir)`, `markComplete(dir)` (the publisher's atomic finish: write `.complete` last after fsync) exported for OGM-045.
- Vitest unit tests (headers, traversal, 404s, incomplete builds, id regex) and a Playwright cross-site test on the GPU flags with the `GM_VERIFY_SOFTWARE_GL=1` fallback.
- `ops/systemd/ogm-games.service` already exists (OGM-002); this service builds to `services/games-host/dist/index.js`, the path `ogm-run games` executes.

## Contract and invariants

Release directory layout and games-origin CSP (owner: this ticket; consumers OGM-045 (writer), OGM-028/075 (iframe), OGM-006, OGM-090 (verify loads builds)):

```
$OGM_GAMES_ROOT/<gameId>/<buildId>/           gameId, buildId: ^[a-z0-9][a-z0-9_-]{0,63}$
  index.html                                  entry; the host serves it for "/" and for a missing path segment
  <bundle>.js, assets/manifest.json, assets/<hash>.<ext> …   as gm build emits them (OGM-063)
  .complete                                   written last by the publisher; absent => 404 for the whole build
URL:  GET /g/<gameId>/<buildId>/[path]        default path index.html; "." or ".." segments => 404; symlinks escaping the build dir => 404
```

Response headers on every `/g/` response (and the static matrix in `src/headers.ts`):

```
Content-Security-Policy: default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:;
  media-src 'self' blob:; font-src 'self'; connect-src 'self' blob: data:; worker-src 'self' blob:; frame-ancestors <OGM_APP_ORIGIN>;
  base-uri 'none'; form-action 'none'; object-src 'none'
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Resource-Policy: cross-origin
Permissions-Policy: microphone=(self), camera=(), geolocation=(), payment=()
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Cache-Control: public, max-age=31536000, immutable
```

Invariants: never `Set-Cookie`; the `Cookie` request header is never read; no directory listing; `/healthz` returns `{ ok: true, service: "games-host", version: "<git sha>", uptimeSec: n }` with `Cache-Control: no-store`; the server binds `127.0.0.1` only (a startup assertion refuses any other host).

## Acceptance and verification

### Agent gate
- `pnpm --filter @ogm/games-host test`: header matrix on `index.html` and on `assets/x.webp`; `..`, encoded `%2e%2e`, absolute and symlink-escape paths → 404; a build without `.complete` → 404 while the same build with it → 200; bad ids (`A`, `..`, 65 chars) → 404; unknown extension → `application/octet-stream` with `nosniff`; `/healthz` shape; `Set-Cookie` absent even when the request carries `Cookie`; startup with `OGM_GAMES_BIND=0.0.0.0` refuses.
- `pnpm --filter @ogm/games-host test:browser`: parent page on `http://127.0.0.1:<p1>` (allowed via `OGM_APP_ORIGIN`) frames `http://127.0.0.1:<p2>/g/demo/b1/index.html` with the T04 attributes; inside the frame `document.cookie === ''`, `fetch('http://127.0.0.1:<p3>/x')` rejects (CSP), `parent.document` throws; a second parent on `http://127.0.0.1:<p4>` (not allowed) gets the frame blocked (`frame.evaluate` fails and the console shows the `frame-ancestors` violation).

## Failure, security, migration and accessibility cases

- CSP `self`-only scripts means a game bundle may not load from a CDN; `gm build` (OGM-063) inlines or copies everything, which is the design.
- `allow-same-origin` + a shared origin lets games read each other's storage (E11-7): recorded limitation; saves go through the bridge (OGM-046), nothing sensitive is stored in the origin.
- A half-written build (publisher crash) is never served: `.complete` gating; `markComplete` fsyncs the directory first.
- Hot-path cost: files are streamed; no in-memory caching in V1.
- No secrets (no env but port, root, app origin); no migrations; no UI beyond headers; 64 px targets do not apply.
