## Outcome

`@gm/sdk/three` creates a renderer with per-tier DPR caps, steps a Rapier world at the SDK's fixed 1/60 s with `takeSnapshot`/`restoreSnapshot` keyframes, and loads GLTF through OGM-026's loader with meshopt and lazy KTX2; `templates/game-3d` is a grey-box scaffold (floor, four walls, one capsule player, two spawns) that boots headless in Chromium on `--use-angle=gl-egl --enable-gpu --ignore-gpu-blocklist` (and under `GM_VERIFY_SOFTWARE_GL=1`), reaches `window.__ready`, answers `advanceTime`, `renderAt` and `renderGameToText`, and renders a non-blank still.

## Context and evidence

The decided 3D stack is Three.js r186 + Rapier (release plan "Stack"; E04-7: `@dimforge/rapier3d-compat` 0.21.0, Apache-2.0, `takeSnapshot`/`restoreSnapshot` exist). The prototypes are r170 and not reusable as code (E04-19: `Clock` deprecated since r183, geometry edited at runtime breaks quantized meshes, E04-8); their proven patterns port as pattern cards (OGM-094), not files. Device tiers are picked once at startup with DPR caps 2/1.5/1 and a frame-time downgrade (E04-14, C4 §3.2), owned by OGM-026; this ticket consumes `pickTier()` and `AssetLoader`. Capture mode on the iGPU is measured (E04-4, E10-4); the template's browser test uses the same flags. Resolved, do not reopen: Rapier only in V1, Jolt deferred (E04-7); the runtime never merges or transforms geometry, build-time tooling does (E04-8); the scaffold is grey-box with no entities beyond the player and spawns (E10-9, B15 §6.2).

## Contract and invariants

Consumer: `GameModule`, `GameInstance`, `GmTestHooks`, `Tier` from OGM-020; `boot`, `Runtime`, `defineFeature` from OGM-022; `pickTier`, `AssetLoader` from OGM-026 (copy its decoder-plugin signature at pickup; do not redefine). This ticket's public shape (`@gm/sdk/three`):

```ts
export function createRenderer(canvas: HTMLCanvasElement, opts: { tier: Tier; antialias?: boolean }): { renderer: WebGLRenderer; resize(w: number, h: number, dpr: number): void; compile(scene: Scene, camera: Camera): Promise<void>; info(): RenderInfo };
export function createPhysics(rt: Runtime, opts?: { gravity?: Vec3 }): Promise<{ world: RAPIER.World; snapshot(): Uint8Array; restore(bytes: Uint8Array): void }>;
export function createGltf(renderer: WebGLRenderer): { loader: GLTFLoader; decode(buf: ArrayBuffer, name: string): Promise<GLTF> };   // meshopt always, KTX2 lazily
export const DPR_CAP: Record<Tier, number>;   // { desktop: 2, mobile: 1.5, low: 1 }  (C4 §3.2)
```

Invariants: `world.step()` is called only from `Runtime.onStep`, never from `requestAnimationFrame`; `renderAt` restores the Rapier snapshot taken with the same keyframe as `serialize()` (registered through the runtime's keyframe hook from OGM-022); the template's `sim.test.ts` runs in Node with no `WebGLRenderer` (Rapier's compat build and Three's scene graph work headless); meshes are views rebuilt from state, never the source of truth (A4 §10.1); no `Math.random`/`Date.now` in `src/` (the OGM-093 lint; grep test here); the template's `design/level.json` has `entities: Record<id, …>` keyed by stable ids (A4 §7 item 9).

## Failure, security, migration and accessibility cases

`RAPIER.init()` failure (no WASM) rejects `boot` with `error {code:'physics_init'}` and the host shows its own message; WebGL context loss triggers `renderer.domElement` `webglcontextlost` → `lifecycle.pause` semantics and an `error {code:'context_lost'}` to the host. A `.ktx2` file on a renderer without support falls back to the WebP variant named in the manifest (OGM-026 chooses; this ticket surfaces `detectSupport`). No secrets in the template; `assets/manifest.json` carries licence ids only. No migrations. Touch targets are host-rendered (OGM-028); the template declares two actions (`move` stick, `jump` button) so the overlay has ≥ 64 px primaries.
