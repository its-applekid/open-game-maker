# OGM-063 plan — gm build assets: tiers, manifest and budgets

## 1. Problem frame

Games must never ship raw pack files: C4 measured that a kit of 174 GLBs becomes 4 files and 8.6 MB becomes 0.8 MB when welded, quantized and meshopt-compressed, and that phones need per-tier triangle and texture budgets (C4 §0–§5). The research chose build-time tiering over import-time variants (D-TIERS, E05-6) and MP3 over Ogg for iPhone (E05-17). This ticket is that build step: lockfile in, content-hashed tiered files plus a manifest conforming to OGM-020's `AssetManifest` out, with a cache and a budget gate.

Requirements trace: R54 → `gm build assets` tiers a game's used assets (weld, quantize, meshopt, WebP, MP3; KTX2 behind a flag) into content-hashed files and a manifest with licence per asset; the mobile budget fails the build. R45 (OGM-026) is served by never deriving names: every file is in the manifest.

Repository conventions: pnpm workspace; package scripts `build`, `test`, `typecheck`, `lint`; Vitest; no Playwright here; no service; no secrets; dependencies added here: `@gltf-transform/core`, `@gltf-transform/functions`, `@gltf-transform/extensions` (MIT, ≈1.5k stars, above the bar), `meshoptimizer` (MIT, ≈6k stars), `sharp` (Apache-2.0, ≈30k stars), each pinned in `packages/gm-cli/package.json`; ffmpeg is a host binary (7.1.5), not a dependency; PR first line `Closes #<issue>`; `## Local tests` with policy, tested head SHA, base, selection, commands and results.

## 3. Implementation units

### U1. Plan: lock → build jobs

Goal: a deterministic list of jobs from the lockfile and the card facts in the repo.

Files: Create `packages/gm-cli/src/commands/build/assets/plan.ts`; Test `test/build-plan.test.ts`.

Approach: `plan(lock, cwd, opts)` runs `gm check assets` logic (import `refusalsForCheck`, fail on any) then groups entries: `kind === 'model'` with `subkind === 'kit'` or triangles < 5,000 and a shared colormap in the same collection → one `kit` job per collection; other models → one `model` job per entry with tiers; `sprite|ui|texture|vfx` → `image` jobs; `audio` → `audio` jobs; `ui/font` → `copy` jobs. Kind/subkind and triangle counts come from the index when `OGM_ASSETS_ROOT` is set, else from a `.gm/assets.meta.json` sidecar written by `gm assets use` (OGM-062 writes `kind`, `subkind`, `triangles`, `pixel_art`; add that to OGM-062 if missing at pickup, as one extra sidecar, not a lock field). Licence per job from the lock entry; `use` mapping: `audience === 'public' && redistribution !== 'none'` → `'any'`, `audience === 'private'` → `'personal'`.

Interface sketch:

```ts
export type BuildJob = { kind: 'kit' | 'model' | 'image' | 'audio' | 'copy'; ids: string[]; inputs: string[]; tiers: Tier[]; license: { id: string; attribution?: string; use: 'any' | 'personal' }; recipe: Record<string, unknown> };
export function plan(lock: AssetsLock, cwd: string, o: { tiers: Tier[] }): BuildJob[];
```

Test scenarios:
- Given two kit entries from one collection, when planned, then one `kit` job with two ids.
- Given a 10k-tri model, then one `model` job with three tiers.
- Given a lock whose check fails, then `plan` throws listing the refusals.
- Given a private Synty entry, then `license.use === 'personal'`.

### U2. Kit and model builders (glTF Transform + meshoptimizer)

Goal: the geometry recipes from C4 §5.3.

Files: Create `kit.ts`, `model.ts`, `gltf.ts` (shared `NodeIO` with `KHRONOS_EXTENSIONS` and the meshopt encoder); Test `test/build-kit.test.ts`, `test/build-model.test.ts`, fixtures `test/fixtures/game/assets/model/<coll>/{wall.glb,tower.glb,colormap.png}`, `monster.glb` (≈10k tris, generated by a fixture script with `@gltf-transform/core`, committed as binary ≤ 200 KB).

Approach: `kit.ts`: for each input `io.read`, then per asset `flatten`, `join`, centre on the base (translate so min y = 0 and x/z centred), drop attributes except POSITION/NORMAL/TEXCOORD_0, `unweld` → set each triangle's UVs to its colormap texel centre → `weld`, write `mesh.extras = { bounds: [w, d, h] }`, name the mesh with the asset id; merge all into one `Document` (`mergeDocuments`), `dedup`, `prune`, `quantize`, `meshopt({ encoder: MeshoptEncoder, level: 'high' })`, write with `extensionsRequired` `EXT_meshopt_compression`; `asset.extras.license = {…}`. `model.ts`: per tier `simplify({ simplifier: MeshoptSimplifier, ratio, error, lockBorder: true })` (ratio 1 / 0.5 / 0.25, error 0.0001 / 0.001 / 0.01), `textureCompress({ encoder: sharp, targetFormat: 'webp', resize: [size, size] })` (2048 / 1024 / 512), `resample`, `quantize`, `meshopt`; skinned models skip `join`/`flatten`/`instance`. Output bytes → sha256 → name `<slug>.<tier|*>.<hash8>.glb`. `tris` counted from primitives' index counts; `gpuTexMB` = Σ width×height×4 (×1.33 mipmaps) / 1 MiB.

Interface sketch:

```ts
export async function buildKit(job: BuildJob, o: BuildOpts): Promise<{ file: OutputFile; meshes: Record<string, { bounds: [number, number, number] }> }>;
export async function buildModel(job: BuildJob, o: BuildOpts): Promise<Record<Tier, OutputFile>>;
export type OutputFile = { name: string; bytes: number; tris?: number; gpuTexMB?: number; decoders: ('meshopt' | 'ktx2')[] };
```

Test scenarios:
- Given the two kit GLBs, when built, then one GLB with meshes named by id, `EXT_meshopt_compression` required, bounds in extras, bytes < sum of inputs.
- Given the 10k model, then `tris` strictly decreases desktop → mobile → low and textures are ≤ 1024 on mobile.
- Given a skinned fixture, then joints survive (skin count unchanged).
- Given identical inputs twice, then identical output names.

Execution note: characterization first on the kit fixture: record input triangle count and bytes in the test so regressions are numbers, not prose.

### U3. Image, audio, font builders and the cache

Goal: the non-geometry outputs and reuse.

Files: Create `image.ts`, `audio.ts`, `font.ts`, `cache.ts`; Test `test/build-media.test.ts`, `test/build-cache.test.ts`.

Approach: `image.ts`: `sharp(input).webp({ lossless: pixelArt, quality: 85 })`, resize above 2048 to 2048 (`maxTexture` check uses the original size for the report); `audio.ts`: `execFile('ffmpeg', ['-y', '-i', input, '-af', 'loudnorm=I=-16:TP=-1.5', '-codec:a', 'libmp3lame', '-q:a', '4', out])`, `-nostdin`, fail with the stderr tail; `font.ts`: copy `.woff2|.ttf|.otf`. `cache.ts`: key `sha256(inputBytes) + '-' + sha256(JSON.stringify(recipe) + toolVersions)`; cached entry stores the output files and the `OutputFile` records; `--no-cache` bypasses.

Test scenarios:
- Given a PNG with `pixel_art`, when built, then WebP lossless (decoded pixels equal).
- Given a WAV, then an MP3 exists and ffprobe reports `mp3` (skip with a named reason when ffmpeg is absent).
- Given a second run, then no builder is invoked (spy) and outputs are identical.

### U4. Manifest, budget and the command

Goal: `gm build assets` end to end.

Files: Create `manifest.ts`, `budget.ts`, `index.ts`; Test `test/build-assets.test.ts`.

Approach: `manifest.ts` assembles `{ version: 1, tiers, files, assets }`, parses with `AssetManifestSchema` (fails the build on any error, printing the Zod path), writes `public/assets/manifest.json` with sorted keys. `budget.ts` computes `AssetBudgetReport` per tier: `bytes` = Σ files reachable from assets at that tier, `files` = their count, `tris`, `gpuTexMB`, `maxTexture`; limits from C4 §5.5 (2 MB, 30, 300k, 100 MB, 1024) overridable by `.gm/budgets.json`. `index.ts`: flags `--tier` (default `desktop,mobile,low`), `--budget` (default `mobile`), `--out` (default `public/assets`), `--ktx2` (exit 2 "toktx not found. Try: gm build assets without --ktx2" when `which toktx` fails), `--json`; prints `tier  bytes  files  tris  gpuTexMB` rows then exceeded lines; exit 1 on exceeded; emits `assets.build`.

Interface sketch (CLI): `gm build assets [--tier desktop,mobile,low] [--budget mobile] [--out public/assets] [--ktx2] [--no-cache] [--strict] [--json]`.

Test scenarios:
- Given the fixture game, when built, then `manifest.json` parses with the OGM-020 schema and every asset resolves a file for every tier.
- Given a lock with a 3 MB texture fixture, then exit 1 and `exceeded` lists `bytes` and `maxTexture`.
- Given `--ktx2` on this host, then exit 2 naming `toktx`.
- Given a corrupt GLB, then that id is reported and the rest builds; with `--strict`, exit 1.

## 5. Deferred to implementation

- Kit threshold (5,000 tris, shared colormap detection by identical texture sha256): tune on Kenney kits; default as stated.
- WebP quality 85 for non-pixel art; lossless for `pixel_art`.
- Whether `audio` loudnorm runs two-pass: single pass (default); two-pass if clipping appears in the fixture.
- Output name slug: last path segment of the id (default) vs full collection-path.
- Where kind/subkind/pixel_art facts come from in a repo without the library: the `.gm/assets.meta.json` sidecar written by `gm assets use` (default; coordinate with OGM-062 if absent).

## 6. Scope boundaries

- Runtime loader, tier pick, downgrade: OGM-026. Manifest type: OGM-020 (file an issue for changes).
- Lockfile and rights: OGM-062 (this ticket runs `gm check assets` first).
- KTX2 encoding, Draco, FBX conversion, pack normalization at import: out (E05-5, E05-7, OGM-064).
- Title-town bake: stays with the town (OGM-071).
- Verify budgets and phone load checks: OGM-090 consumes the report.

## 7. Risks

- `@gltf-transform` major version drift (v4 API): pin at install and record the version in the recipe hash so cached outputs invalidate on upgrade.
- `meshoptimizer` WASM init is async: call `MeshoptEncoder.ready` once in `gltf.ts`.
- Netlify serves GLB uncompressed (T05 §7): meshopt inside the file is the mitigation; measure bytes, not gzip.
- Skinned Kenney characters through the kit path would break rigs: the planner routes `rig` cards to `model` jobs; default threshold logic excludes any card with a `rig` block.
- OGM-020 schema stricter than C4's example (no `built`/`source`): emit exactly the T04 type (default); provenance stays in the lock.
