## Outcome

`@gm/sdk` core boots a `GameModule` behind the bridge: `boot(module)` answers the host's `hello` with `ready` and marks, runs a fixed 1/60 s clock with a seeded RNG, dispatches `design.apply` to `applyDesign` and replies `design.applied`, routes `save.restore`/`save.write` through `restore`/`serialize`, and serves every `GmTestHooks` call over `test.*` and, in draft and test builds only, as `window.__gm`, `window.render_game_to_text` and `window.advanceTime`; a fixture game with no engine passes the suite in Node.

## Context and evidence

The prototype proved that a fixed-step hook makes the whole loop testable (`dungeon.js:861-865` `tick(sec)`, E04-2, E10-11) and the title town proved draw-at-absolute-time capture (`city.js:943-958`, E04-3). D-HOOKS fixes one surface and its aliases; T10 §4 states what verify needs from it. The game side of the editor contract is small: `applyDesign` deterministic given the doc (E04-15, E08-17), `serialize` doubles as `renderGameToText`'s source (A9 §3.1), entities keyed by stable id. Resolved, do not reopen: `advanceTime(ms)` steps a 1/60 s accumulator with no render until the last step; `renderAt(ms)` restores the last keyframe and advances forward (physics cannot jump back, E04-3); globals exist only when the build kind is `draft` or `test`, decided at build time, and conformance check 8 (OGM-029) proves their absence in published bundles; `renderGameToText` is capped at 64 KB with `truncated: true` (T04 risk 7).

## Scope

- `packages/sdk/src/core/`: `boot(module, opts)` (bridge handshake via `openGameBridge`, capability negotiation, `mount`, lifecycle, `mode.set`, `design.apply` → `applyDesign` → `design.applied`, `save.*`, `settings`, `viewport` fan-out through `HostApi`), `clock.ts` (fixed step, accumulator, `tick` counter, pause halts within one step), `rng.ts` (seeded, `setSeed`, `seed()`), `events.ts` (ring buffer for `events(since)`), `registry.ts` (features register schema, controls, save slice: A4 §10.1).
- `packages/sdk/src/test/`: `hooks.ts` implementing `GmTestHooks` over the clock and the module (`advanceTime`, `renderAt` with keyframes from `serialize`/`restore`, `renderGameToText`, `renderInfo` delegating to the engine wrapper's counter or zeros, `hitTest` delegating to `pick`, `inject` feeding the next step's `ActionFrame`, `probes`, `events`, `marks`), `globals.ts` (installs `window.__gm`, `render_game_to_text`, `advanceTime`, `__frame`, `__ready`, `__marks`, `__gm.tick(seconds)` when `build !== 'published'`), `dispatch.ts` (`test.*` envelopes → hooks → `test.result`).
- A pure fixture game `packages/sdk/test/fixtures/counter-game.ts` (no engine: a counter entity map, two controls, a save slice, `net` hooks) used by every test.

- Also owns the bug-bundle recorder in the SDK core (A9 §3.2 / T10 E10-10): a ring buffer of the last ~30 s of `ActionFrame`s and a `renderGameToText()` keyframe every 10 s, exposed as `hooks.bundle()` for the host's report button (OGM-071) and the repair replay (OGM-096).

## Contract and invariants

Consumer: copy `GameModule`, `GameInstance`, `HostApi`, `GmTestHooks`, `ActionFrame` from OGM-020 `packages/contracts/src/{game,input}.ts`; do not redefine. Bridge: `openGameBridge` from OGM-021. This ticket's own public shape (`@gm/sdk`):

```ts
export function boot<D, S>(module: GameModule<D, S>, opts?: { hostOrigin?: string; build?: 'draft' | 'test' | 'published'; headless?: boolean }): Promise<Runtime<D, S>>;
export interface Runtime<D, S> {
  instance: GameInstance<D, S>; clock: Clock; rng: Rng; hooks: GmTestHooks; host: HostApi;
  onFrame(cb: (dt: number) => void): () => void;          // render callbacks; never called inside advanceTime except the last step
  onStep(cb: (dt: number, frames: ActionFrame[]) => void): () => void;   // fixed-step simulation callbacks
}
export interface Clock { tick: number; dt: 1 / 60; paused: boolean; advance(ms: number): number /* steps run */; pause(): void; resume(): void }
export interface Rng { next(): number; int(n: number): number; seed(): number; setSeed(s: number): void }
export function defineFeature<D, S>(f: { id: string; schema: ZodType; controls: ControlDecl[]; save?: SaveSlice<S>; system?: (rt: Runtime) => void }): Feature;
```

Invariants: `applyDesign` is called once per `design.apply` and the reply carries the same `rev`; two runtimes given the same seed, design and injected frames produce byte-equal `renderGameToText()` after N steps (determinism test); `pause()` stops `onStep` within one step and `advanceTime` while paused runs nothing; `renderAt(t)` with `t <` current time restores the last keyframe ≤ `t` then advances; `renderGameToText().state` deep-equals `serialize().data`; `inject(frame)` is consumed by exactly the next step; globals are absent when `build === 'published'`; `marks` begin with `['start', ms]` and end with `['frame0', ms]` before `ready` flips true; no `Math.random`/`Date.now` in `src/core` or `src/test` (the OGM-093 lint rule, enforced here by a grep test today).

## Failure, security, migration and accessibility cases

A throwing `applyDesign` replies `design.applied`? No: it replies `error {code:'apply_failed'}` and leaves the previous design in place (the host keeps the last good doc, A4 §9). A throwing hook replies `test.result {ok:false, error}` and never crashes the loop. `save.restore` with a `saveSchemaVersion` the module cannot migrate replies `error {code:'save_unsupported'}`. Globals are a debug surface: never installed in published builds, and `boot` refuses `build: 'published'` when `location.search` contains `build=test` (misconfiguration trap). No secrets reach the SDK. No migrations, no UI.
