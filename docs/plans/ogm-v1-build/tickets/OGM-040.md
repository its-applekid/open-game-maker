## Outcome

`pnpm --filter @ogm/design-log test` passes with property tests proving that for any design doc and any transaction list, `replay(apply)` round-trips, `invert` undoes byte-exactly, and `reduce(log)` is order-stable; `packages/contracts/src/{design-log,branches,releases,saves}.ts` export the T08 §4 types as Zod schemas with emitted JSON Schema and fixtures, so OGM-041 to OGM-048, OGM-053 and OGM-075 can import them.

## Context and evidence

The editor transaction is the one record that is persisted, replayed for branches, broadcast to room watchers and undone (E08-1). The research held two incompatible persistence models; D-LOG settles it: the append-only per-branch log is the source of truth and the working set is a derived cache (E08-2, E08-3). Nothing in the prototypes is reusable: `prototypes/ui-v0/site/js/dungeon.js` lines 70–79 undo by pushing whole-map JSON strings onto an 80-entry stack with counter ids (E08-15). Resolved, do not reopen: entities are `Record<id, Entity>`, never arrays (A4 §7 item 9), so every Immer patch path is `['entities', id, ...]` and last-write-per-path reduction is exact (E08-10); `origin` is replaced by `actor` + `kind` (B7 §2); `kind: 'merge'` exists for OGM-044; Kevin's counter version scheme (D-VERSION) is derived, never stored.

## Contract and invariants

Producer. The exact TypeScript from T08 §4, to be transcribed into Zod without renaming a field (ids are ULIDs, times ISO strings):

```ts
export type Patch = { op: 'replace' | 'add' | 'remove'; path: (string | number)[]; value?: unknown }; // immer Patch
export type DesignDoc = { schemaVersion: number; globals: Record<string, unknown>; entities: Record<string, Entity> };
export type Entity = { id: string; prefab: string; level: string; origin: 'build' | 'creator'; props: Record<string, unknown> };
export type EditorCommand =
  | { op: 'set'; control: string; targets: string[] | 'global'; value: unknown }
  | { op: 'invoke'; command: string; args: unknown; targets?: string[] }
  | { op: 'reset'; control: string; targets: string[] | 'global' };
export type Transaction = {
  id: string; gameId: string; branchId: string;
  rev: number; baseRev: number; leaseToken: number; actor: string;
  kind: 'manual' | 'system' | 'merge'; label: string; baseBuildId: string;
  commands: EditorCommand[]; patches: Patch[]; inverse: Patch[]; createdAt: string;
};
export type OverrideKey = `${string}@${string}`;
export type OverrideEntry = { key: OverrideKey; controlId: string; targetId: string | 'global'; value: unknown; baseValueAtEdit: unknown; txId: string; rev: number;
  status: 'carried' | 'renamed' | 'needs_choice' | 'conflict' | 'dropped';
  reason?: 'value_invalid' | 'control_removed' | 'target_removed' | 'superseded_by_job' | 'builder_changed' | 'migration_failed' };
export type EntityOverride =
  | { kind: 'create'; entityId: string; parent: string; prefab: string; props: Record<string, unknown>; txId: string }
  | { kind: 'delete'; entityId: string; txId: string };
export type WorkingSet = { gameId: string; branchId: string; buildId: string; headRev: number; entries: Record<OverrideKey, OverrideEntry>; entityOps: Record<string, EntityOverride> };
export type ReapplyReport = { gameId: string; branchId: string; fromBuildId: string; toBuildId: string; carried: OverrideKey[]; renamed: { from: OverrideKey; to: OverrideKey }[];
  needsChoice: { key: OverrideKey; mine: unknown; allowed: unknown }[]; conflicts: { key: OverrideKey; mine: unknown; builder: unknown }[]; dropped: { key: OverrideKey; reason: OverrideEntry['reason'] }[] };
export type Branch = { id: string; gameId: string; name: string; gitRef: string; forkPoint: { parentBranchId: string; parentRev: number; gitSha: string } | null;
  headRev: number; latestBuildId: string | null; status: 'active' | 'archived' | 'merged'; createdBy: string; createdAt: string };
export type FieldChange = { path: string; before: unknown; after: unknown; txId: string };
export type SideDelta = Record<string, FieldChange | 'deleted'>;
export type MergeConflict = { id: string; path: string; entityId?: string; controlId?: string; kind: 'both_changed' | 'delete_vs_edit' | 'control_removed';
  ours: FieldChange | 'deleted' | 'removed_by_build'; theirs: FieldChange | 'deleted' | 'removed_by_build'; resolution?: 'ours' | 'theirs' | 'both' | { value: unknown } };
export type MergePlan = { id: string; gameId: string; sourceBranchId: string; targetBranchId: string; baseRev: number; auto: Patch[]; conflicts: MergeConflict[];
  code: 'clean' | 'fast_forward' | { conflictJobId: string }; previewBuildId?: string; status: 'planned' | 'resolving' | 'previewing' | 'landed' | 'abandoned' };
export type Build = { id: string; gameId: string; branchId: string; gitSha: string; jobId?: string; sdkVersion: string; saveSchemaVersion: number; migratesFromSchema?: number;
  achievementCatalogHash: string; status: 'building' | 'tested' | 'failed'; artifact: 'present' | 'gc'; createdAt: string };
export type OverrideSnapshot = { id: string; gameId: string; branchId: string; buildId: string; headRev: number; sha256: string; entries: OverrideEntry[]; entityOps: EntityOverride[] };
export type Release = { id: string; gameId: string; seq: number; version: string; buildId: string; snapshotId: string; gitTag: string; kind: 'publish' | 'rollback';
  restoresReleaseId?: string; predecessorReleaseId?: string; changelog: { summary: string; items: ChangeNote[] }; publishedBy: string; publishedAt: string };
export type ChangeNote = { jobId?: string; txId?: string; kind: 'fix' | 'add' | 'change' | 'remove'; text: string };
export type SaveSlot = { userId: string; gameId: string; slotId: 'auto' | '1' | '2' | '3'; kind: 'auto' | 'manual'; label?: string; headRevision: number;
  status: 'ok' | 'needs_migration' | 'unsupported_old' | 'incompatible_after_rollback' };
export type SaveRevision = { userId: string; gameId: string; slotId: string; revision: number; branchId: string; buildId: string; releaseId?: string; saveSchemaVersion: number;
  payload: Uint8Array; sha256: string; deviceId: string; clientSeq: number;
  reason: 'pause' | 'checkpoint' | 'interval' | 'hidden' | 'manual' | 'migration' | 'update'; migratedFromRevision?: number; createdAt: string };
export type PlayLease = { userId: string; gameId: string; deviceId: string; tabId: string; expiresAt: string };
export type AchievementDef = { key: string; title: string; description: string; icon: string; hidden: boolean; progress?: { target: number }; retired?: boolean };
export type AnalyticsEvent = { ts: string; gameId: string; branchId: string; releaseId?: string; env: 'draft' | 'published'; pseudoUserId: string; sessionId: string;
  name: string; scope?: string; marker?: string; outcome?: 'complete' | 'fail' | 'quit'; props?: Record<string, unknown> };
```

File placement: `design-log.ts` = Patch…ReapplyReport; `branches.ts` = Branch…MergePlan; `releases.ts` = Build…ChangeNote; `saves.ts` = SaveSlot, SaveRevision, PlayLease, AchievementDef, AnalyticsEvent (the player-record family). Invariants: `rev` is server-assigned and monotonic per branch; `entities` is a map keyed by host-minted id; `apply(doc, tx.patches)` then `apply(·, tx.inverse)` is byte-identical under canonical JSON; `reduce` of the same multiset of transactions in rev order is deterministic; `replay(branch)` = parent chain to `forkPoint.parentRev`, then the branch's transactions in rev order. T07's `DesignTx` (room relay) is a projection of `Transaction` with JSON-pointer paths; OGM-050 owns that projection and may import `Transaction` here.

## Acceptance and verification

### Agent gate
- `pnpm --filter @ogm/design-log test`: property tests (apply/invert round-trip, replay(apply) identity, reduce order-stability, reduce last-write-per-path, replay across a fork point equals replay of the parent prefix plus branch suffix); each fails if the corresponding function is stubbed.
- `pnpm --filter @ogm/contracts test`: every fixture validates against its emitted schema; a fixture with `entities` as an array is rejected.
- `pnpm -r typecheck` and `pnpm lint` green.

### Human or e2e evidence
- None.

## Failure, security, migration and accessibility cases

Patches that would turn `entities` into an array, or a path not rooted at `globals` or `entities`, are rejected by `validate.ts` before apply (rooms rely on this, R76). Oversized transactions (patches above 256 KB canonical) are rejected with a typed error for OGM-041 to map to 413. No secrets, no I/O, no migrations, no UI.
