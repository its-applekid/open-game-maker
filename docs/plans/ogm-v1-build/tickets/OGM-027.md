## Outcome

Inside any game iframe, `gm.audio` owns one `AudioContext` with `music | sfx | amb | voice` buses, unlocks on the first `pointerup`/`touchend` (with `audioSession.type = 'playback'`), plays MP3 samples with pitch variation, ZzFX effects and an optional Tone.js `song.json`, renders any cue offline to `{peakDb, rmsDb}` for the verify gates, and, when the host enables it, posts cues as `audio.relay` messages so iOS can play them in the parent page.

## Context and evidence

- E04-20: Web Audio buses, Tone.js 15 for `song.json`, ZzFX for SFX (806 stars, recorded exception), MP3 samples (Safari cannot decode Ogg; the studio converts every Kenney Ogg to MP3, `prototypes/studio-v0/tools/build.sh:31-50`). Tone.js 15 deprecated the global `Transport`: use `getTransport()`.
- E04-6: iOS unlocks on `pointerup`/`touchend`/`keydown`/`click`, not `pointerdown`; `navigator.audioSession.type = 'playback'` keeps sound with the ringer on silent; the title town plays its cues in the parent because "iOS never lets an iframe start its own" (`city.js:893-896`). Cross-origin `allow="autoplay"` is untested on a real iPhone: the relay stays as the fallback.
- A9 §3.6: `renderCue()` over `OfflineAudioContext` is the hook the loudness checks need; it only works if games route audio through the SDK mixer.
- Resolved: Tone.js is an optional subpath import so 2D arcade games do not pay its weight; `audio.relay` is a `GameToHost` message owned by OGM-020.

## Scope

- `createAudio({ bridge?, rng, loader?, settings? })` → `GmAudio`: `unlock()`, `status()` (`'tap' | 'on' | 'off'`), buses with gains, `play(id, {vol, pitch, rate, bus})`, `playOneOf(ids, opts)`, `music(id, {fade, loop?: [start, end]})`, `zzfx(params, {vol, bus})`, `song(json)` (dynamic import of `./song`), `stop()`, `applySettings({mute, volume})`, `renderCue(id): Promise<{peakDb, rmsDb}>`, `relay(on)`.
- Unlock listeners registered with `capture: true` on `pointerup`, `touchend`, `keydown`, `click`; the silent-buffer kick for old iOS; `visibilitychange` suspend/resume; `statechange` replays what should be playing (`sound.js:153-205`).
- Relay: when `relay(true)` (host decides after a failed unlock or per device) every `play`/`music` becomes `audio.relay` `{cue, vol, rate}` / `{loop, gain}` over the bridge; local output muted.
- `song.json` v1 schema (Zod) in `song.ts`: bpm, loop bars, tracks of Tone instruments with note patterns; `getTransport()` scheduling; `dispose()` on `stop()`.
- Pitch variation and `playOneOf` draw from the SDK seeded RNG (OGM-022), never `Math.random`.

## Contract and invariants

Consumer of OGM-020: copy from OGM-020 `packages/contracts/{bridge}.ts`; do not redefine. The message this ticket emits, as T04 §4 states it:

```ts
| Envelope<'audio.relay', { cue: string; vol: number; rate: number } | { loop: string; gain: number }>  // iOS fallback
```
and consumes `Envelope<'settings', { mute: boolean; volume: number; textScale: number; reduceMotion: boolean }>` (mute and volume only).

Module API (owner: this ticket, from T04 §4): `unlock()` (first `pointerup`/`touchend`, sets `audioSession.type='playback'`), buses `music|sfx|amb|voice`, `play(id, {vol, pitch, rate, bus})`, `music(id, {fade})`, `zzfx(params)`, `song(songJson)` (Tone.js, optional import), `renderCue(id): Promise<{peakDb, rmsDb}>` (OfflineAudioContext).

Invariants: exactly one `AudioContext` per game; every source reaches `destination` through a bus then `master`; nothing plays while `state !== 'running'` except through the relay; `renderCue` never touches the live context; the Tone.js chunk is not in the bundle unless `song()` is called.

## Failure, security, migration and accessibility cases

- `decodeAudioData` failure (bad file) logs once with the id and resolves `null`; `play` of a null buffer is a no-op (`audio.js:39`).
- iOS reports `interrupted` as well as `suspended`; `unlock` treats both as not running (`sound.js:171`).
- `navigator.audioSession` is absent outside Safari; wrapped in try/catch.
- A `song.json` with more than 16 tracks or notes outside bar range is rejected by the schema, never partially scheduled.
- No secrets, no migrations. Accessibility: `reduceMotion` is not audio; mute and volume come only from the host `settings` message so the platform HUD stays the single control (64 px targets live there, OGM-075).
