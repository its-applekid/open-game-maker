## Outcome

`gm-sdk check <gameDir>` builds a game in `test` and `published` kinds, serves them on `127.0.0.1`, mounts each through `@gm/host` in headless Chromium on this machine's GPU (SwiftShader with `GM_VERIFY_SOFTWARE_GL=1`), runs the nine A4 §10.3 checks plus B7's two, writes `conformance.json` (renderer string, per-check pass/fail/unchecked with detail, stills), exits 1 on any failure, and passes green on `templates/game-3d` and `templates/game-2d` (and `templates/game-multiplayer` when it exists).

## Context and evidence

- E04-17: the nine deterministic checks (manifest valid and ids unique; every control min/max/default round-trips byte-equal; save round-trip; previous-release save migrates; boot with each optional capability disabled; pause halts within one frame; desktop 16:9 and iPad 4:3 stills inside the safe area; debug adapter absent from the published bundle; override hints present) plus B7 §2: entity ids in `design/` survive across builds unless retired; every palette item and tool round-trips through undo. `gm-verify` (OGM-093) calls this rather than re-implementing.
- E04-2, E04-3: hook names are fixed by D-HOOKS (`advanceTime`, `renderAt`, `renderGameToText`, `renderInfo`, `hitTest`, `setSeed`, `inject`, `ready`, `marks`) over `test.*` bridge messages; window globals exist only in draft/test builds (check 8).
- E04-4, E10-4, E10-5: the iGPU works headless through `--use-angle=gl-egl --enable-gpu --ignore-gpu-blocklist` (`ANGLE (Intel, Mesa Intel(R) UHD Graphics (CML GT2)…)`); SwiftShader is the no-flag default; Playwright 1.64.1 and Chromium 1248 are cached; one iGPU is shared, so D-VERIFY-GPU caps captures at 2.
- Resolved: A9 §3.5 "CI is SwiftShader" is superseded (D-VERIFY-GPU); the runner reports the renderer string so a SwiftShader run is never mistaken for a GPU one (godogen's trap, B14).

## Scope

- Package `@gm/sdk-conformance` with bin `gm-sdk` (`check` subcommand): `--previous <dir>` (last tested build's `manifest.json` and `design/`), `--out <dir>`, `--json`, `--browser chromium|webkit` (webkit optional), `--software-gl`.
- Runner: builds the game with the OGM-022 build-kind flag for `test` and `published`; static server on `127.0.0.1:0`; a host page built from `@gm/host` (`createGameFrame` with `build: 'test'`, `mode: 'test'`, role `owner`); drives hooks through `frame.request('test.*')`.
- Checks C1–C11 as named in the plan, each a module in `src/checks/` returning `{ id, status: 'pass' | 'fail' | 'unchecked', detail, artifacts? }`; `unchecked` only when the input is absent (no previous build, no save fixture, no multiplayer template) and never silently.
- Report: `conformance.json` `{ sdkProtocol, renderer, gl: 'gpu' | 'software', game, checks[], stills[] }`; human one-line-per-check output; exit 1 on any `fail`.
- Workspace script `pnpm conformance` running the templates; CI job added by this ticket only to `packages/sdk-conformance`'s own `test` (the template runs are part of `ci / required` only when the GPU runner exists there; otherwise `--software-gl`).

## Contract and invariants

Consumer of OGM-020: copy from OGM-020 `packages/contracts/{bridge,game}.ts`; do not redefine. The hook surface this runner drives, as T04 §4 states it:

```ts
export interface GmTestHooks {                      // bridge `test.*`; also window globals in draft/test builds only
  ready: boolean; marks: [string, number][];
  advanceTime(ms: number): void;                    // fixed 1/60 s steps, no render until the last step (dungeon.js tick)
  renderAt(ms: number): void;                       // keyframe + advanceTime to absolute time, one render (city.js __frame)
  renderGameToText(): { coords: string; tick: number; mode: 'play' | 'edit'; state: unknown; players: unknown[] };
  renderInfo(): { calls: number; triangles: number; frameMs: number };
  hitTest(nx: number, ny: number): boolean;
  setSeed(seed: number): void; inject(frame: ActionFrame): void;
}
```
and `GameModule.manifest` / `controls: ControlDecl<D>[]` (ids, `path`, `min`, `max`, `default`, `aliases`, `retired`, `migrateOverride` hints) and `GameInstance.applyDesign`, `serialize`, `restore`, `migrate` through the `design.apply`, `save.restore`, `save.write` messages.

Owner (this ticket): the `conformance.json` report shape above and check ids `C1`–`C11`; OGM-093 reads them; additive changes only.

Invariants: every check is deterministic (seed set to 1 before each; no wall-clock waits except the pause check's real-time guard); a check never passes by absence of input; the renderer string is always recorded; the published bundle is never loaded with test capabilities.

## Failure, security, migration and accessibility cases

- Build failure, no `ready` within 60 s, or a page error → the run stops with `fail` on `C0 boot` and the console tail; later checks are `unchecked` with reason `boot-failed`, never `pass`.
- The published build is mounted with `capabilities: []` and `build: 'published'`; C8 also greps the bundle for `render_game_to_text` and `__gm`.
- Only 2 concurrent browsers host-wide (D-VERIFY-GPU): the runner takes OGM-090's semaphore when present; otherwise one browser per process.
- No secrets, no network beyond `127.0.0.1`, no migrations. C7 enforces the safe area and a non-blank still so unreadable layouts fail here before a human looks.
