# Editor mockups (frames of reference only)

Kevin's example editor views, shared 2026-10-21. Use them to frame research (direct manipulation, category rail, item palette, contextual inspector, big Try it / Test Drive button, undo/redo, saved state).

> **Version scope (2026-10-25):** The "kid-oriented" look of `dungeon-editor.png` is a visual reference only; kid-first framing is superseded (general game maker, V1 adults only). The interaction patterns listed above are age-neutral V1 editor references (B7). See `docs/spec/release-plan.md` for V1/V2/V3 scope.

They are **not** the design spec. Kevin will author the full UI design spec separately with Claude Design.

- `dungeon-editor.png`: kid-oriented dungeon editor (Rooms/Monsters/Treasure/Decor, "How many?" stepper, Easy/Medium/Tough).
- `racetrack-editor.png`: low-poly 3D track editor (Select/Build/Paint/Raise/Erase tools, sliders, snap to grid, race settings).
