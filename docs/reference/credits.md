# Credits

Each game build regenerates `CREDITS.md` and publishes `credits.json` from `assets.lock.json`. The pause menu’s
**Credits** screen groups used packs by licence and shows their attribution and source. This is the same host HUD for
2D and 3D games.

Game Maker **Settings → Credits** lists packs used by every current game build in the signed-in family, followed by
the fonts and third-party libraries the app ships. Private licensed packs are identified as private and linked to
their public vendor source; raw files and download actions are never exposed.
